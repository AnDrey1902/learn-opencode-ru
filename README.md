## 📚 Содержание курса

```
Этап 1: Быстрый старт (обязательно · 30 минут)
    ↓   Установка, настройка сети, подключение модели, первый диалог
Этап 2: Повседневное использование (обязательно · 1,5 часа)
    ↓   Интерфейс, управление сессиями, ссылки на файлы
Этап 3: Эффективный рабочий процесс (обязательно · 1 час)
    ↓   Режимы Plan/Build, совместная работа Agent, инициализация проекта
Этап 4: Практика по сценариям (по желанию · выберите один трек)
    │
    ├── ✍️  Создание контента: посты, соцсети, рассказы, сценарии, маркетинговые тексты
    ├── 💻 Разработка: повседневное программирование, рефакторинг и тесты, документация Git, CI/CD
    └── 📊 Офисная продуктивность: организация файлов, обработка данных, скрипты автоматизации
    ↓
Этап 5: Глубокая настройка (по желанию · по необходимости)
        Пользовательские Agent, Skill, команды, расширения MCP, интеграция с IDE
```

## 🚀 Начать сейчас

### Читать онлайн (рекомендуется)

👉 **<a href="/" target="_blank">learnopencode.com</a>**

### Локальный запуск

Замените `YOUR-FORK` в команде на адрес вашего форка:

```bash
# Клонируйте репозиторий
git clone https://github.com/YOUR-FORK/learn-opencode.git
cd learn-opencode

# Установите зависимости
npm install

# Запустите сервер разработки
npm run dev
```

### Развёртывание в Vercel

В репозитории уже есть файл `vercel.json`. Для сборки проекта используйте:

```bash
npm run build
```
