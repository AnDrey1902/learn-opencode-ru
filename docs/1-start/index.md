# Этап 1: быстрый старт

> 💡 **Цель**: установить OpenCode и успешно провести диалог за 30 минут

## 🎯 Цели этапа

- Успешно установить OpenCode без ошибок
- Настроить сетевое подключение (особенно важно для пользователей в Китае)
- Провести первый диалог «Hello World»

## ⏳ Примерная продолжительность

25–45 минут

## 🚀 Перед началом

- Компьютер с доступом в интернет (Windows / macOS / Linux)
- Терминал (рекомендуются WezTerm / iTerm2 / Windows Terminal)
- Стакан воды ☕

## 🎒 Что вы получите

После этого этапа вы сможете:

1. Запускать команду `opencode` в терминале
2. Настроить сеть (или выбрать китайскую модель с прямым подключением)
3. Провести первый диалог с ИИ
