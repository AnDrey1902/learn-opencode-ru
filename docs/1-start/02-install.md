**Установка за 3 шага**: команда → перезапуск терминала → проверка.

|---|---|
| macOS / Linux | `curl -fsSL https://opencode.ai/install \\| bash` |

## Основная идея

Установка OpenCode состоит из трёх шагов:

1. Выполнить команду установки
2. Перезапустить терминал (чтобы применился PATH)
3. Проверить установку

## Повторяйте за мной
<AdInArticle />

### Пользователи macOS / Linux

Скопируйте приведённую ниже команду, вставьте её в терминал и нажмите Enter:

```bash
curl -fsSL https://opencode.ai/install | bash
```

::: details Что вы увидите (при успешной установке)
```
Installing OpenCode...

→ Detected: macOS arm64
→ Downloading opencode-darwin-arm64...
  ████████████████████████████████████████ 100%
→ Installing to ~/.opencode/bin/opencode...
→ Updating shell configuration...

✓ Installation complete!

To get started, restart your terminal and run:

  opencode
```
:::

Если вы видите `Installation complete!`, установка прошла успешно.

---

### Пользователи Windows

В Windows рекомендуется установка через **Scoop** (права администратора не нужны).

**Если Scoop уже установлен:**

```powershell
scoop install opencode
```

::: details Scoop не установлен? Нажмите, чтобы открыть инструкции
Откройте **PowerShell** (рекомендуются обычные права пользователя) и **выполняйте** приведённые команды **по очереди**:

**Шаг 1: разрешите запуск скриптов (выполняется один раз)**

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

**Шаг 2: установите Scoop**

```powershell
Invoke-RestMethod -Uri https://get.scoop.sh | Invoke-Expression
```

> **⚠️ PowerShell запущен от имени администратора?**
>
> Если PowerShell запущен **от имени администратора** (в заголовке окна есть слово «Администратор»), предыдущая команда завершится ошибкой. Используйте эту команду:
>
> ```powershell
> iex "& {$(irm get.scoop.sh)} -RunAsAdmin"
> ```

**Шаг 3: установите Git (Scoop использует Git для добавления bucket)**

```powershell
scoop install git
```

**Шаг 4: установите OpenCode**

```powershell
scoop install opencode
```
:::

::: tip Другие способы установки в Windows
Если вы предпочитаете Chocolatey, npm, Docker и другие способы, см. [1.2a Альтернативные способы установки](./02a-install-alternatives).
:::

### Перезапустите терминал

**Зачем перезапускать?**

Скрипт установки изменил переменную окружения (PATH), но текущий терминал всё ещё использует старую конфигурацию. После перезапуска команда `opencode` будет распознаваться.

**Как перезапустить:**

1. Закройте текущее окно терминала (нажмите крестик или Cmd+Q / Alt+F4)
2. Откройте терминал снова

::: details Не хотите закрывать окно?
Можно вручную перезагрузить конфигурацию:

**macOS/Linux (zsh):**
```bash
source ~/.zshrc
```

**macOS/Linux (bash):**
```bash
source ~/.bashrc
```

Но я рекомендую просто перезапустить терминал — так надёжнее.
:::

### Проверка установки

Введите:

```bash
opencode --version
```

**Вы должны увидеть:**

```
opencode x.x.x
```

Номер версии меняется с обновлениями; если он отображается, установка прошла успешно.

## 🚀 Хотите попробовать прямо сейчас? (необязательно)

После успешной установки можно сразу запустить OpenCode и попробовать бесплатную модель:

```bash
opencode
```

После запуска введите `/models`, выберите бесплатную модель с суффиксом `-free` (например, `opencode/glm-4.7-free`) и отправьте любое сообщение.

::: tip Подсказка
Бесплатные модели не требуют регистрации и API Key, поэтому отлично подходят для быстрого знакомства. Подробнее: [1.4a Бесплатные модели](./04a-free-models).
:::

## 🖥️ Настольное приложение (необязательно)

Если вы предпочитаете графический интерфейс, у OpenCode есть и настольное приложение.

### Скачивание и установка

| Платформа | Способ скачивания |
|------|---------|
| **macOS (Apple Silicon)** | Скачайте `opencode-desktop-darwin-aarch64.dmg` из [GitHub Releases](https://github.com/anomalyco/opencode/releases) |
| **macOS (Intel)** | Скачайте `opencode-desktop-darwin-x64.dmg` |
| **Windows** | Скачайте `opencode-desktop-windows-x64.exe` |
| **Linux** | `.deb`, `.rpm` или AppImage |

**Установка через менеджер пакетов:**

```bash
# macOS Homebrew
brew install --cask opencode-desktop

# Windows Scoop
scoop bucket add extras
scoop install extras/opencode-desktop
```

### Настольная и терминальная версии

| Возможность | Терминальная версия (TUI) | Настольная версия |
|------|-------------|--------|
| Интерфейс | Командная строка | Графическое окно |
| Системные уведомления | ✅ Поддерживаются, по умолчанию выключены | ✅ Автоматическое уведомление о завершении задачи |
| Несколько окон | ❌ Одно окно | ✅ Поддержка нескольких вкладок |
| Сложность установки | Простая | Немного сложнее (нужно скачать установщик) |

::: tip Рекомендация
Рекомендуется установить обе версии. Для повседневной работы используйте терминальную (она эффективнее), а для долгих задач — настольную (её можно свернуть, и она уведомит вас о завершении).
:::

В терминальной версии уведомления можно включить в `tui.json`, задав `attention.enabled: true`, а с помощью `attention.notifications` выбрать типы уведомлений: вопросы, права, завершение и ошибки. По умолчанию функция выключена.
