## Повторяйте за мной

### Шаг 1: зарегистрируйтесь и получите API Key

Откройте платформу MiniMax (эксклюзивная ссылка для читателей сайта со скидкой 10%):

https://platform.minimaxi.com/subscribe/token-plan?code=2OOzWR9jAE&source=link

::: tip Рекомендуемые тарифы
Рекомендуется приобрести тариф **Max** или **Pro** в **Token Plan**:
- **Max**: лучший выбор для активных пользователей, большой объём по выгодной цене
- **Pro**: достаточно для повседневной разработки, хорошее соотношение цены и возможностей

После оформления подписки скопируйте персональный API Key на странице «Управление тарифом»:

> 💡 На скриншоте показана страница Token Plan: выберите «Token Plan» в меню слева и нажмите «Копировать» в разделе API Key.

### Шаг 2: подключите MiniMax в OpenCode

Способ A (рекомендуется попробовать первым):

1. Запустите OpenCode:
   ```bash
   opencode
   ```
2. Введите:
   ```
   /connect
   ```
3. Найдите `MiniMax`, выберите **MiniMax Coding Plan (minimaxi.com)** и вставьте API Key.

> 💡 Пользователям в Китае рекомендуется выбирать вариант с суффиксом `(minimaxi.com)`.


### Шаг 3: выберите модель и проверьте подключение

Введите:

```
/models
```

Выберите `MiniMax-M2.7` или `MiniMax-M2.7-highspeed` (либо другую модель из настроенного списка), затем отправьте фразу для проверки:

```
你好，请介绍一下你自己
```

## Типичные проблемы

| Симптом | Причина | Решение |
|-----|------|------|
| `Cannot read properties of undefined` | Неполная конфигурация или неверный Key | Проверьте настройки baseURL и apiKey |
| Нет ответа | Конфликт переменных окружения | Удалите переменные окружения вроде `ANTHROPIC_AUTH_TOKEN` |
