# Подключение OpenAI (GPT-5.2 / Codex)

> Примерное время: 10 минут

OpenAI — компания, создавшая ChatGPT, и поставщик одних из самых мощных моделей ИИ. Выпущенная в декабре 2025 года **GPT-5.2** — актуальная флагманская модель, а **GPT-5.2-Codex** оптимизирована специально для задач программирования.

::: warning Пользователям в Китае
Для доступа к OpenAI нужен прокси. Сначала завершите [1.3 Настройка сети](./03-network).

Если не удаётся настроить сеть, рекомендуется использовать китайские модели, например [Zhipu](./04c-zhipu) или [DeepSeek](./04b-deepseek).
:::

---

## Что вы сможете после урока

- Войти в OpenCode напрямую с подпиской ChatGPT
- Или подключить OpenAI с помощью API Key
- Использовать новейшие модели GPT-5.2, GPT-5.2-Codex и другие

## Два способа входа

| Способ | Для кого | Преимущество |
|------|--------|------|
| **Подписка ChatGPT** (рекомендуется) | Пользователи с Plus/Pro | Можно пользоваться напрямую, без дополнительных расходов |
| **API Key** | Пользователи без подписки | Оплата по использованию |

## Способ 1: вход по подписке ChatGPT (рекомендуется)

Если у вас уже есть **ChatGPT Plus** ($20/месяц) или **ChatGPT Pro** ($200/месяц), можно войти по подписке напрямую и не покупать API отдельно.

### 🎒 Перед началом

- [ ] Завершить [1.2 Установка](./02-install) и уметь запускать `opencode`
- [ ] Завершить [1.3 Настройка сети](./03-network) (обязательно для пользователей в Китае)
- [ ] Иметь подписку ChatGPT Plus или Pro

### Повторяйте за мной

#### Шаг 1: запустите OpenCode

```bash
opencode
```

#### Шаг 2: подключите OpenAI

Введите:

```
/connect
```

С помощью клавиш со стрелками найдите **OpenAI** и нажмите Enter.

#### Шаг 3: выберите способ входа

Появится список способов входа:

```
┌ Select auth method
│
│ ChatGPT Plus/Pro(рекомендуется)
│ Create an API Key
│ Manually enter API Key
└
```

Выберите **ChatGPT Plus/Pro** и нажмите Enter.

#### Шаг 4: авторизация в браузере

OpenCode автоматически откроет браузер и перейдёт на страницу входа OpenAI.

1. Войдите с помощью аккаунта ChatGPT
2. Нажмите **Авторизовать**
3. После сообщения «Авторизация успешна» вернитесь в терминал

#### Шаг 5: проверьте подключение

Вернитесь в OpenCode. Вы увидите:

```
✓ Login successful
```

Теперь введите `/models` — вы должны увидеть все модели OpenAI. Если вы только что получили доступ к новой модели, но список не обновился, выполните `opencode models --refresh` в системном терминале для обновления кэша, затем снова откройте `/models`.

## Способ 2: вход с API Key

Если у вас нет подписки ChatGPT, используйте API Key с оплатой по факту использования.

### 🎒 Перед началом

- [ ] Завершить [1.2 Установка](./02-install)
- [ ] Завершить [1.3 Настройка сети](./03-network) (обязательно для пользователей в Китае)
- [ ] Иметь международный способ оплаты (Visa / Mastercard)

### Повторяйте за мной

#### Шаг 1: зарегистрируйте аккаунт OpenAI

Откройте: https://platform.openai.com

Нажмите **Sign up**, зарегистрируйтесь и войдите по подсказкам.

#### Шаг 2: получите API Key

1. После входа выберите **API keys** в меню слева
2. Или перейдите напрямую: https://platform.openai.com/api-keys
3. Нажмите **Create new secret key**
4. Назовите Key (например, `opencode`)
5. **Сразу скопируйте и сохраните его**

::: warning Показывается только один раз!
API Key показывается только один раз и исчезает после закрытия окна. Сразу скопируйте его в безопасное место.
:::

#### Шаг 3: пополните баланс

1. Откройте: https://platform.openai.com/settings/organization/billing
2. Нажмите **Add payment method**
3. Добавьте банковскую карту и пополните баланс (для начала рекомендуется внести $5)

#### Шаг 4: подключитесь в OpenCode

Запустите OpenCode и введите:

```
/connect
```

Выберите **OpenAI**, затем **Manually enter API Key**.

Вставьте свой API Key:

```
┌ API key
│ sk-xxxxxxxxxxxxxxxxxxxxxxxx
└ Нажми Enter для подтверждения
```

## Выбор модели

После успешного подключения введите:

```
/models
```

Вы увидите список моделей OpenAI. Ниже приведены актуальные рекомендации на январь 2026 года:

### Серия GPT-5.2 (новейшие флагманские модели)

| Модель | Особенности | Подходит для |
|------|------|----------|
| `gpt-5.2-chat-latest` (Instant) | Быстрые ответы для повседневного использования | Вопросы и ответы, документы, переводы |
| `gpt-5.2` (Thinking) | Глубокое мышление для сложных задач | Анализ, планирование, трудные задачи |
| `gpt-5.2-pro` | Самая мощная и точная | Профессиональная и научная работа |
| `gpt-5.2-codex` | **Специально для кода** | Написание кода, рефакторинг, отладка |

### Как выбрать?

- **Повседневное использование**: `gpt-5.2-chat-latest` (быстрая)
- **Сложные задачи**: `gpt-5.2` (мощная)
- **Написание кода**: `gpt-5.2-codex` (специализированная)

Выберите модель клавишами со стрелками и нажмите Enter.

## Подробно о GPT-5.2-Codex

### Что такое GPT-5.2-Codex?

GPT-5.2-Codex — **профессиональная модель для кода**, выпущенная OpenAI 18 декабря 2025 года. Она дополнительно оптимизирована на основе GPT-5.2 для задач разработки ПО.

Её особенности:

- **Длительные задачи**: поддерживает сжатие контекста и умеет работать с большими кодовыми базами
- **Масштабный рефакторинг**: хорошо справляется с переносом и рефакторингом кода и другими сложными задачами
- **Улучшенное визуальное понимание**: понимает макеты, скриншоты и технические диаграммы
- **Кибербезопасность**: отлично находит уязвимости и проводит аудит кода

### Когда использовать Codex?

| Сценарий | Рекомендуемая модель | Причина |
|------|----------|------|
| Написание сложных функций | ✅ GPT-5.2-Codex | Хорошо поддерживает длительные задачи |
| Масштабный рефакторинг | ✅ GPT-5.2-Codex | Специально оптимизирована |
| Перенос кода | ✅ GPT-5.2-Codex | Работает с большими кодовыми базами |
| Отладка ошибок | ✅ GPT-5.2-Codex | Глубже понимает логику кода |
| Повседневные вопросы | GPT-5.2 Instant | Быстрее |
| Создание документов | GPT-5.2 Instant | Универсальных возможностей достаточно |

**Проще говоря**: для кода используйте Codex, для остальных задач — GPT-5.2 Instant.

### Переключение на Codex

Введите:

```
/models
```

С помощью клавиш со стрелками найдите `openai / gpt-5.2-codex` и нажмите Enter.

### Попробуйте Codex

После переключения на Codex попробуйте этот запрос:

```
Напиши функцию Node.js, которая:
1. Читает все .md-файлы в указанной папке
2. Извлекает заголовок каждого файла (первая строка с #)
3. Генерирует индексный файл index.md
```

Вы заметите, что Codex особенно хорошо понимает многошаговые задачи и создаёт код с удачной структурой.

### Советы по использованию Codex

**1. Давайте достаточно контекста**

Чем лучше Codex понимает проект, тем точнее результат. Ссылайтесь на нужные файлы с помощью `@`:

```
@src/routes/user.ts @src/middleware/auth.ts

Добавь проверку прав в маршруты пользователей
```

**2. Чётко описывайте цель**

Не говорите «оптимизируй эту функцию» — уточните, что именно нужно улучшить:

```
У этой функции проблемы с производительностью: на больших данных тормозит.
Оптимизируй её, цели:
1. Меньше запросов к базе
2. Добавить кэш
3. Сохранить интерфейс как есть
```

**3. Сначала попросите проанализировать, потом действовать**

Для сложных задач сначала попросите Codex провести анализ:

```
Сначала разбери структуру кода модуля, потом расскажи, как будешь рефакторить
```

После анализа убедитесь, что выбран правильный подход, и только потом попросите его действовать.

**4. Используйте визуальные возможности**

Codex понимает скриншоты и макеты, поэтому можно написать:

```
@design.png

Сверстай страницу по этому макету
```

## Типичные проблемы

| Симптом | Причина | Решение |
|-----|------|------|
| После авторизации в браузере ничего не происходит | Проблема с сетью | Проверьте прокси и обновите страницу |
| `connection timeout` | Проблема с сетью | Проверьте настройки прокси, см. [1.3 Настройка сети](./03-network) |
| `API key invalid` | Key скопирован неправильно | Скопируйте его заново и убедитесь, что лишних пробелов нет |
| `insufficient_quota` | Недостаточно средств | Пополните баланс в консоли OpenAI |
| Страница не открывается | Прокси выключен или нестабилен | Попробуйте другой узел прокси |

## Стоимость

### Пользователи с подпиской ChatGPT

- **Plus**: $20/месяц, включает всю серию моделей GPT-5.2
- **Pro**: $200/месяц, более высокий лимит и доступ к GPT-5.2 Pro

### Пользователи API

Оплата взимается за токены (токен ≈ 0,75 английского слова ≈ 0,5 китайского иероглифа):

| Модель | Цена ввода | Цена вывода |
|------|----------|----------|
| gpt-5.2 / gpt-5.2-chat-latest | $1.75/миллион | $14/миллион |
| gpt-5.2-pro | $21/миллион | $168/миллион |

При обычном использовании выходит примерно $0,1–0,5 в день.
