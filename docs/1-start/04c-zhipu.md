Какая китайская модель лучше всего оправдывает покупку? **GLM-5 сейчас предлагает лучшее соотношение цены и возможностей**:

- **Непревзойдённый китайский язык**: первоклассное понимание и выражение мыслей в написании, обобщении и переводе
- **Сильное программирование**: рассуждения, программирование и возможности агентов на уровне SOTA среди открытых моделей
- **Стабильный доступ**: прямое подключение в Китае, без обхода блокировок, быстрые ответы
- **Отличная цена**: тариф Coding Plan **от 49 юаней/месяц**, намного дешевле оплаты по использованию

### 🎯 Ключевые преимущества GLM-5

| Возможность | Описание |
|------|------|
| Глубокие рассуждения | Анализ сложной логики, планирование многошаговых задач |
| Генерация кода | Корректный синтаксис, единый стиль, готовый к запуску код |
| Работа агентов | Agent автоматически вызывает инструменты и выполняет многоэтапные задачи |
| Китайский язык | Редактура текстов, обобщение документов, технический перевод |

**Тариф Pro дополнительно открывает** (настоятельно рекомендуется):
- 🌐 **Веб-поиск**: поиск актуальной информации в реальном времени

- 📄 **Чтение веб-страниц**: достаточно передать ссылку для обобщения содержимого
- 📦 **Анализ репозиториев с открытым кодом**: прямое чтение кодовой базы GitHub

## Повторяйте за мной

### Шаг 1: зарегистрируйтесь и получите API Key

Для регистрации и входа рекомендуется использовать ссылку:

- **Эксклюзивная ссылка сайта (скидка 10%)**: [https://www.bigmodel.cn/glm-coding?ic=PNSI6JU6FP](https://www.bigmodel.cn/glm-coding?ic=PNSI6JU6FP)

> **Подсказка**:
> - Рекомендуется выбрать тариф Pro: он даёт доступ к GLM-5 и расширенным возможностям, например веб-поиску.
> - Сразу сохраните полученный Key (не отправляйте его в чаты и не публикуйте на GitHub).

---

### Шаг 2: подключите Zhipu в OpenCode

Запустите OpenCode:

```bash
opencode
```

Введите:

```
/connect
```

Найдите в списке поставщиков и выберите:

- `Zhipu AI Coding Plan`

Затем вставьте свой API Key.

---

### Шаг 3: выберите модель GLM-5

Введите:

```
/models
```

Выберите `glm-5`.

---

### Шаг 4: отправьте первую фразу (проверка)

```
你好，请介绍一下你自己
```

Если вы получили ответ, подключение успешно.

## Типичные проблемы

| Симптом | Причина | Решение |
|-----|------|------|
| Нет варианта `Zhipu AI Coding Plan` | Слишком старая версия OpenCode | Обновите: `opencode upgrade` |
| `API key invalid` | Неверный формат Key | Убедитесь, что Key полный (формат похож на `xxx.xxx`) |
| Медленный ответ или тайм-аут | Нестабильная сеть | Проверьте сеть или повторите в другое время |

## 💡 Советы по выбору тарифа

У Coding Plan есть три тарифа (цена при непрерывной помесячной оплате):

| Тариф | Цена | Для кого |
|------|------|--------|
| Lite | 49 юаней/месяц | Лёгкое использование |
| **Pro** | 149 юаней/месяц | Основной тариф для ежедневной работы, лучшее соотношение цены и возможностей (рекомендуется) |
| Max | 469 юаней/месяц | Активные пользователи, большой лимит |

**Настоятельно рекомендуется Pro**:
- ✅ Поддерживает новейшую флагманскую модель GLM-5
- ✅ Лимита хватает для повседневной разработки
- ✅ Открывает веб-поиск, понимание изображений, анализ репозиториев с открытым кодом и другие расширенные возможности
- ✅ Генерация быстрее, чем в Lite
