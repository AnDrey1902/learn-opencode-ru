# Подключение Claude (Anthropic)

Claude — большая языковая модель Anthropic, отлично справляющаяся со сложными задачами программирования и имеющая длинное контекстное окно на 200K токенов.

При работе из Китая обычно сначала нужно завершить [1.3 Настройка сети](./03-network), иначе может возникнуть тайм-аут подключения.

## Повторяйте за мной

### Шаг 1: получите API Key Anthropic

Получите API Key в консоли Anthropic:

1. Откройте [console.anthropic.com](https://console.anthropic.com)
2. Войдите или зарегистрируйте аккаунт
3. Нажмите **API Keys** → **Create Key**
4. Скопируйте созданный API Key (формат: `sk-ant-...`)

::: warning Безопасность
- API Key показывается только один раз — сразу сохраните его
- Не публикуйте API Key в репозитории кода
- Регулярно меняйте API Key
:::

**Вы должны увидеть** строку вроде `sk-ant-api03-xxxx-xxxx-xxxx`

### Шаг 2: настройте ключ в OpenCode

OpenCode предлагает два способа настройки — выберите подходящий:

#### Способ 1: переменная окружения (рекомендуется)

Задайте API Key как переменную окружения:

::: code-group

```bash [macOS/Linux（临时）]
export ANTHROPIC_API_KEY=sk-ant-api03-your-key-here
opencode
```

```bash [macOS/Linux（永久）]
# 添加到 ~/.bashrc 或 ~/.zshrc
echo 'export ANTHROPIC_API_KEY=sk-ant-api03-your-key-here' >> ~/.zshrc
source ~/.zshrc
opencode
```

```powershell [Windows（临时）]
$env:ANTHROPIC_API_KEY="sk-ant-api03-your-key-here"
opencode
```

```powershell [Windows（永久）]
# 添加到系统环境变量
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_API_KEY", "sk-ant-api03-your-key-here", "User")
```

:::

#### Способ 2: команда аутентификации OpenCode

Выполните команду аутентификации — OpenCode сохранит API Key локально:

```bash
opencode auth login
```

Затем:

1. Выберите `Anthropic`
2. Вставьте API Key
3. Нажмите Enter для завершения

**Вы должны увидеть**: `Done` или `Login successful`

::: details Расположение данных аутентификации
OpenCode хранит данные аутентификации здесь:
- **Все платформы**: `~/.local/share/opencode/auth.json` (согласно стандарту XDG)
:::

### Шаг 3: проверьте конфигурацию

Проверьте, успешно ли настроен поставщик Anthropic:

```bash
opencode auth list
```

**Вы должны увидеть:**

```
Credentials ~/.local/share/opencode/auth.json
● Anthropic api

Environment
● Anthropic ANTHROPIC_API_KEY
```

Это означает, что поставщик Anthropic успешно настроен.

### Шаг 4: просмотрите доступные модели

Просмотрите все модели Anthropic:

```bash
opencode models
```

**Вы должны увидеть** примерно следующее:

```
anthropic/claude-3-5-haiku-20241022
anthropic/claude-3-5-sonnet-20241022
anthropic/claude-3-7-sonnet-20250219
anthropic/claude-opus-4-20250514
...
```

::: tip Полная информация о моделях
Команда `opencode models --verbose` показывает подробные метаданные: названия моделей, стоимость и другие сведения.
:::

### Шаг 5: проведите первый диалог

Запустите OpenCode и выберите модель Claude:

```bash
cd /path/to/your/project
opencode
```

В интерфейсе OpenCode введите первый вопрос:

```
帮我写一个简单的 HTTP 服务器
```

**Вы должны увидеть:**

1. ИИ начнёт создавать ответ (с использованием модели Claude)
2. Возможно, он вызовет инструменты для создания файлов
3. Будут представлены полный код и объяснение

Anthropic предлагает несколько моделей Claude — выбирайте по своим задачам:

| Модель | ID модели | Контекстное окно | Особенности | Подходит для |
|------|---------|-----------|------|---------|

## Типичные проблемы

### API Key недействителен

**Симптом**: появляется `Authentication failed` или `Invalid API Key`

**Причины**:
- неверный формат API Key (не начинается с `sk-ant-`);
- API Key истёк или отозван;
- у API Key нет доступа к указанной модели.

**Решение**:
1. Проверьте формат API Key
2. Создайте новый API Key в консоли Anthropic
3. Убедитесь, что на аккаунте достаточно средств или действует подписка

### Не удалось подключиться к сети

**Симптом**: появляется `Network error` или `Connection timeout`

**Причины**:
- API Anthropic недоступен (может потребоваться прокси)
- нестабильная сеть

**Решение**:
1. Проверьте сетевое подключение
2. Настройте прокси при необходимости:

```bash
export HTTP_PROXY=http://your-proxy:port
export HTTPS_PROXY=http://your-proxy:port
```

### Модель недоступна

**Симптом**: появляется `Model not found` или список моделей пуст

**Причины**:
- у API Key нет доступа к этой модели;
- модель снята с использования или переименована.

**Решение**:
1. Проверьте разрешения на доступ к моделям в консоли Anthropic
2. Выполните `opencode models`, чтобы увидеть доступные модели
3. Перейдите на более высокий тариф для доступа к большему числу моделей
