## Основное понятие: что такое API Key?

Перед настройкой разберёмся с одним понятием.

### Что такое API Key

Проще говоря, **API Key — это «удостоверение личности» для доступа к сервисам ИИ.**

Точнее:
- компании, создающие ИИ (DeepSeek, Zhipu, MiniMax и другие), предоставляют сервисы ИИ;
- чтобы пользоваться сервисом, нужен идентификатор пользователя;
- таким идентификатором служит API Key;
- он также используется для расчёта оплаты (сколько использовали, столько и списывается).

### Важные замечания об API Key

::: danger Важно: защищайте свой Key
- **Не передавайте его другим**: с Key можно тратить средства с вашего аккаунта.
- **Не публикуйте его на GitHub**: существуют боты, которые специально сканируют GitHub в поисках ключей.
- **Не отправляйте скриншоты в соцсети**: вы понимаете почему.

Если ключ всё же утёк, немедленно удалите старый Key на сайте провайдера и создайте новый.
:::

## Два способа настройки

OpenCode предлагает два способа настроить поставщика моделей:

| Способ | Где используется | Команда |
|------|------|------|
| **В TUI** | Настройка в интерфейсе после запуска OpenCode | `/connect` |
| **Терминальный CLI** | Настройка в командной строке до запуска | `opencode auth login` |

Оба способа дают один и тот же результат — выбирайте удобный.

### Способ 1: /connect в TUI

В интерфейсе OpenCode введите:

```
/connect
```

Появится экран выбора поставщика; следуйте подсказкам.

### Способ 2: opencode auth login в терминале

**До** запуска OpenCode выполните в терминале:

```bash
opencode auth login
```

Появится список поставщиков:

```
? Select provider
❯ OpenCode (recommended)
  Anthropic (Claude Max or API key)
  GitHub Copilot (ChatGPT Plus/Pro or API key)
  OpenAI (ChatGPT Plus/Pro or API key)
  Google
  ...
```

После выбора введите API Key или завершите OAuth по подсказкам.

### Просмотр настроенных поставщиков

```bash
opencode auth list
# или коротко
opencode auth ls
```

Вы увидите:

```
Credentials ~/.local/share/opencode/auth.json
√ OpenCode api

Environment
√ OpenCode OPENCODE_API_KEY
```

### Приоритет аутентификации

OpenCode ищет данные аутентификации в следующем порядке:

1. **Переменные окружения** (например, `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`)
2. **Файл auth.json** (`~/.local/share/opencode/auth.json`)
3. Данные аутентификации в **файле конфигурации**

::: tip Автоматическое обнаружение переменных окружения
При запуске OpenCode **автоматически сканирует переменные окружения системы** и включает соответствующего поставщика, если находит доступный API Key. Иными словами, достаточно задать переменную в системе — ничего добавлять в файл конфигурации не нужно.

**Переменные окружения для разных поставщиков**:

| Поставщик | Переменная окружения |
|--------|-----------|
| Anthropic (Claude) | `ANTHROPIC_API_KEY` |
| OpenAI (GPT) | `OPENAI_API_KEY` |
| DeepSeek | `DEEPSEEK_API_KEY` |
| Google (Gemini) | `GOOGLE_GENERATIVE_AI_API_KEY` или `GEMINI_API_KEY` |

**Пример настройки** (для Anthropic):

```bash
# macOS / Linux (временно, действует в текущем терминале)
export ANTHROPIC_API_KEY=sk-ant-api03-xxxxx

# macOS / Linux (навсегда, записать в ~/.zshrc или ~/.bashrc)
echo 'export ANTHROPIC_API_KEY=sk-ant-api03-xxxxx' >> ~/.zshrc
source ~/.zshrc

# Windows PowerShell (навсегда)
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_API_KEY", "sk-ant-api03-xxxxx", "User")
```

После настройки перезапустите OpenCode и введите `/models`, чтобы увидеть модели соответствующего поставщика.
:::

::: info Расположение учётных данных
`~/.local/share/opencode/auth.json` (единый путь для всех платформ, согласно стандарту XDG)
:::

## Переключение моделей

После настройки нескольких моделей переключайтесь между ними в TUI командой `/models`:

```
/models
```

Выберите модель клавишами <kbd>↑</kbd> и <kbd>↓</kbd>, затем нажмите <kbd>Enter</kbd>.

::: tip Настройка модели по умолчанию
Чтобы задать модель по умолчанию, настройте поле `model` в `opencode.json`. ID модели должен **полностью совпадать** с ID в списке `/models`; при ручном вводе легко ошибиться, поэтому лучше скопировать всю строку.

```bash
# Сначала смотрим доступные ID моделей в терминале
opencode models
```

```json
{
  "model": "deepseek/deepseek-chat"  // ← скопируй строку целиком из списка opencode models, не вбивай руками
}
```
:::
