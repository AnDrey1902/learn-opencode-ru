# Подключение Qwen (Alibaba Cloud)

> Примерное время: 5–10 минут

Qwen — большая языковая модель Alibaba Cloud, предоставляющая API через платформу Model Studio (DashScope). Она отличается широкими возможностями, развитой экосистемой и большим выбором моделей.

Если вы ещё не читали, что такое API Key, сначала вернитесь к [обзору 1.4](./04-connect) и разберитесь с понятием.

---

## Что вы сможете после урока

- Получить API Key Alibaba Cloud Model Studio
- Подключить Qwen в OpenCode
- Выбрать подходящую модель под задачу
- Отправить первую фразу и получить ответ

## Повторяйте за мной

### Шаг 1: зарегистрируйте аккаунт Alibaba Cloud

Откройте: https://bailian.console.aliyun.com

Если у вас нет аккаунта Alibaba Cloud, зарегистрируйтесь по подсказкам страницы и пройдите проверку личности.

---

### Шаг 2: подключите сервис Model Studio

1. Откройте консоль Model Studio
2. Подключите сервис DashScope по подсказкам
3. Примите соглашение об использовании сервиса

---

### Шаг 3: получите API Key

1. Откройте страницу управления API-KEY
   - или перейдите напрямую: https://bailian.console.aliyun.com/#/api-key
2. Создайте новый API Key
3. **Сразу скопируйте и сохраните его**

::: warning Показывается только один раз!
API Key показывается только один раз. После закрытия окна полный Key больше не будет виден.

Сразу скопируйте его в безопасное место, не отправляйте в чаты, не делайте скриншоты и не публикуйте на GitHub.
:::

---

### Шаг 4: подключите Qwen в OpenCode

Запустите OpenCode:

```bash
opencode
```

Введите:

```
/connect
```

Найдите в списке поставщиков и выберите:

- **Пользователи в материковом Китае**: выберите `Alibaba (China)` или найдите `alibaba-cn`
- **Пользователи за рубежом**: выберите `Alibaba` или найдите `alibaba`

Затем вставьте свой API Key.

После успеха вы увидите примерно следующее:

```
✓ Provider added successfully!
```

::: tip Международная и китайская версии
Эти версии используют разные конечные точки API:
- китайская (`alibaba-cn`): `dashscope.aliyuncs.com`
- международная (`alibaba`): `dashscope-intl.aliyuncs.com`

В материковом Китае неверный выбор версии может привести к тайм-ауту или сбою подключения.
:::

---

### Шаг 5: выберите модель и проверьте подключение

Введите:

```
/models
```

Выберите модель под свою задачу:

| Сценарий | Рекомендуемая модель | Описание |
|------|---------|------|
| Разработка | `qwen3-coder-flash` | Контекст 1M, вывод 65K, специально для кода |
| Общий диалог | `qwen-plus`, `qwen-turbo` | Хорошее соотношение цены и возможностей, поддержка рассуждений |
| Глубокие рассуждения | `qwq-plus` | Поддержка reasoning, подходит для сложных вопросов |
| Понимание изображений | `qwen-vl-max` | Поддержка изображений на входе |

После выбора модели отправьте фразу для проверки:

```
Привет! Расскажи о себе
```

Если вы получили ответ, подключение успешно.

## Использование переменной окружения (необязательно)

Помимо настройки через `/connect`, можно использовать переменную окружения:

```bash
# Способ 1: задать при запуске
DASHSCOPE_API_KEY=sk-xxx opencode

# Способ 2: записать в конфиг shell
echo 'export DASHSCOPE_API_KEY=sk-xxx' >> ~/.zshrc
source ~/.zshrc
```

---

## Пользовательская настройка через файл (расширенный вариант)

Если нужно настроить собственный baseURL или добавить модели, укажите их в `opencode.json`:

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "alibaba-cn": {
      "options": {
        "baseURL": "https://dashscope.aliyuncs.com/compatible-mode/v1"
      }
    }
  }
}
```

---

## Типичные проблемы

| Симптом | Причина | Решение |
|-----|------|------|
| `API key invalid` | Key скопирован неверно или сервис не подключён | Подключите Model Studio и получите Key заново |
| Нет варианта Alibaba | Слишком старая версия OpenCode | Обновите OpenCode: `opencode upgrade` |
| Сообщение о недостаточном балансе | Бесплатная квота закончилась | Пополните баланс в консоли |
| Требуется проверка личности | Alibaba Cloud требует подтверждения личности | Пройдите проверку и повторите попытку |
| Тайм-аут подключения | Выбрана неверная международная/китайская версия | Пользователям в материковом Китае нужно выбрать `alibaba-cn` |
| Некоторые модели не поддерживают tool_call | Не все модели умеют вызывать инструменты | Используйте `qwen-plus` или `qwen3-coder-flash` |
