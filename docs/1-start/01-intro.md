## В двух словах

**OpenCode — ИИ-помощник для программирования, работающий в терминале.**

Вы формулируете задачу одной фразой, а он помогает понять проект, изменить код, выполнить команды и автоматически завершить многошаговую задачу.

---

## Vibe Coding: говорим, а не печатаем

В последнее время набирает популярность понятие **Vibe Coding**.

Главная идея: **чтобы изменить код или написать текст, достаточно описать задачу словами — делать всё вручную не нужно.**

| Традиционный подход | Vibe Coding |
|---------|-------------|
| Открыть IDE → найти файл → найти код → изменить вручную → сохранить → протестировать | Вы говорите «добавь обработку ошибок» → ИИ всё меняет → тесты проходят → готово |
| Вы исполнитель | Вы командир, ИИ — исполнитель |

Если достаточно говорить, зачем вообще нужна IDE?

## Два типа инструментов для программирования с ИИ

### IDE

**Примеры**: Cursor, Windsurf, GitHub Copilot, Trae

**Особенности**:
- Графический интерфейс: результат виден сразу
- ИИ выступает «вторым пилотом» редактора
- Вы всё ещё главный исполнитель и должны следить за экраном

**Подходит**: тем, кто привык к IDE и хочет видеть изменения во время работы

### TUI (инструменты с терминальным интерфейсом)

**Примеры**: Claude Code, Codex CLI, OpenCode

**Особенности**:
- Нативная работа в терминале, лёгкость и скорость
- ИИ — основной исполнитель, вы — командир
- Можно запускать несколько задач параллельно и не следить за экраном
- Программируемость, автоматизация и интеграция в CI/CD

**Подходит**: для Vibe Coding, привычной работы в терминале и задач автоматизации

**OpenCode относится к TUI-инструментам.**

## Сравнение TUI-инструментов

Сейчас среди TUI-инструментов есть три основных варианта:

### Claude Code (официальный инструмент Anthropic)

- **Модели**: серия Claude 4.5 (Opus, Sonnet)
- **Цена**: $20/месяц (входит в Claude Pro)
- **Плюсы**: официальный продукт Anthropic, отлаженный интерфейс, поддержка плагинов VS Code/JetBrains
- **Минусы**: привязан к моделям Claude, не поддерживает китайские модели, неудобен для доступа из Китая

### Codex CLI (официальный инструмент OpenAI)

- **Модели**: GPT-5.2 / GPT-5-Codex
- **Цена**: $20/месяц (входит в ChatGPT Plus)
- **Плюсы**: асинхронное выполнение в облаке, параллельные задачи, автоматический запуск тестов
- **Минусы**: привязан к серии GPT, не поддерживает китайские модели, неудобен для доступа из Китая

### OpenCode (проект сообщества с открытым исходным кодом)

- **Модели**: свободное переключение между 75+ моделями
- **Цена**: бесплатно (вместе с китайскими тарифами моделей, например [GLM-5 от Zhipu от ¥20 в месяц](/1-start/04c-zhipu))
- **Плюсы**: конфиденциальность данных (прямой доступ к API/локальная работа), открытый исходный код, свобода выбора моделей, нативная поддержка Zhipu/DeepSeek/Qwen/MiniMax, качественная работа с китайским языком, кроссплатформенность (macOS/Linux/Windows)

### Как выбрать?

| Ваша ситуация | Рекомендация |
|---------|------|
| Хотите использовать китайские модели | OpenCode |
| Бюджет не ограничен, важен официальный продукт | Claude Code или Codex CLI |
| Хотите открытый и управляемый инструмент | OpenCode |

## Что он умеет

### Для программистов: 30-минутная работа за 3 минуты

```
你：@src/components/Button.tsx 按钮点击没反应，帮我看看

AI：问题在第 23 行，handleClick 没调用 preventDefault()，
    按钮在 form 里会触发提交导致页面刷新。要我改吗？

你：改吧

AI：已修改，刷新页面测试一下
```

Также умеет: разбираться в незнакомом коде, писать новые функции, рефакторить, создавать тесты и делать ревью кода.

---

### Для авторов: три варианта, когда не получается писать

```
你：@第42章.md 卡住了，男主发现女主秘密，不知道怎么写他的反应

AI：根据男主人设，三个方向：
    1. 压抑型 - 假装不知道，暗中疏远
    2. 质问型 - 直接摊牌，矛盾升级
    3. 试探型 - 旁敲侧击，增加悬疑
    建议方向三，需要我写个开头吗？
```

Также умеет: продумывать планы, создавать персонажей, редактировать тексты и менять формат сценария.

---

### Для всех: 800 файлов за 5 минут

```
你：@./临时文件夹 帮我整理，按类型分类

AI：发现 847 个文件：PDF 126个、图片 589个、文档 95个、其他 37个
    建议创建子文件夹按类型分，PDF 再按年份分。执行吗？

你：执行

AI：完成，移动了 847 个文件
```

Также умеет: обрабатывать таблицы, массово переименовывать файлы, создавать отчёты и обучать программированию.

## Для кого подходит

| Кто вы | Подходит? | Причина |
|-------|-------|------|
| Программист, привыкший к терминалу | ✅ Отлично подходит | Нативная среда, легко начать |
| Программист, привыкший к IDE | ⚠️ Зависит от ситуации | Можно использовать вместе с IDE или выбрать Cursor |
| Автор контента | ✅ Подходит | Удобно работать с текстовыми файлами |
| Пользователь, желающий повысить эффективность | ✅ Подходит | Практичен для организации файлов и обработки данных |
| Совсем не хотите работать с терминалом | ❌ Скорее не подходит | OpenCode — терминальный инструмент |

::: tip Честная рекомендация
Если вы совсем не хотите работать с командной строкой, вам, возможно, больше подойдут Cursor или Claude Desktop.
Цель этого курса — быстро показать возможности OpenCode, а решение вы примете сами.
:::
