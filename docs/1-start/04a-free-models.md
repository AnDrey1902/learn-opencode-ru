# Бесплатные модели

> Подходит, если вы хотите провести первый диалог в OpenCode **без затрат и настройки**.

В OpenCode встроен ряд **полностью бесплатных** моделей: **регистрация и API Key не нужны**, можно пользоваться ими сразу после установки.

---

## Доступные бесплатные модели

| ID модели | Название | Особенности |
|---------|------|------|
| `glm-5-free` | GLM-5 | От Zhipu, поддерживает рассуждения, отлично работает с китайским языком |
| `minimax-m2.7-free` | MiniMax M2.7 | От MiniMax, поддерживает рассуждения, контекст 200K |
| `gpt-5-nano` | GPT-5 Nano | От OpenAI, лёгкая и быстрая |
| `kimi-k2.5-free` | Kimi K2.5 | От Moonshot AI, поддерживает рассуждения, контекст 256K |
| `big-pickle` | Big Pickle | Скрытая модель, временный бесплатный доступ |

::: tip Примечание
Список бесплатных моделей со временем меняется — ориентируйтесь на список, который показывает команда `/models`.

Для бесплатных моделей действуют лимиты на уровне IP, поэтому они подходят для знакомства и лёгкого использования. Для большего лимита войдите в OpenCode Zen и получите API Key.
:::

---

## Повторяйте за мной

### Шаг 1: запустите OpenCode

```bash
opencode
```

При первом запуске OpenCode автоматически загрузит бесплатные модели; настройка не требуется.

---

### Шаг 2: выберите бесплатную модель

Введите:

```
/models
```

Выберите в списке любую бесплатную модель, например:
- `opencode/glm-4.7-free`
- `opencode/minimax-m2.1-free`

::: tip Как узнать бесплатную модель?
Обычно у бесплатных моделей есть суффикс `-free`, либо в списке `/models` указана цена `$0`.
:::

---

### Шаг 3: отправьте первую фразу

```
Привет! Расскажи о себе
```

Если вы получили ответ, значит, весь процесс «установка → выбор модели → диалог» успешно пройден.

---

## Проверка

- [ ] Команда `/models` показывает `opencode/*-free` или модель с ценой `$0`
- [ ] После отправки сообщения вы получаете ответ ИИ

---

## Частые вопросы

| Симптом | Причина | Решение |
|-----|------|------|
| В `/models` нет бесплатных моделей | Проблема с сетью или устаревшая версия | Проверьте сеть и обновите программу командой `opencode upgrade` |
| Запрос отклонён/сработал лимит | Для бесплатных моделей действуют квоты на уровне IP | Выберите другую бесплатную модель или повторите попытку позже |
| Ответ приходит медленно | Сервер бесплатной модели сильно загружен | Это нормально: подождите или выберите другую модель |

## Нужно больше?

Бесплатные модели подходят для знакомства и лёгкого использования. Если вам нужны:
- более высокие квоты запросов;
- больший выбор моделей (Claude, GPT-5 и другие);
- более стабильный сервис,

войдите в [OpenCode Zen](https://opencode.ai/zen), чтобы получить API Key, и ознакомьтесь с разделом [1.4 Подключение модели](./04-connect).
