# Подключение GitHub Copilot

> Примерное время: 5–10 минут

Если у вас **уже есть подписка GitHub Copilot** (личная за $10/месяц или корпоративная), её можно использовать в OpenCode для вызова моделей GPT-4o, Claude и других без отдельной покупки API.

::: tip Для кого подходит?
- Для пользователей с подпиской GitHub Copilot
- Для тех, кто не хочет отдельно покупать API OpenAI/Anthropic
- Для тех, кто хочет использовать модели Copilot в терминале
:::

Если у вас нет подписки Copilot, рекомендуем пропустить эту страницу и обратиться к другим руководствам по подключению.

## Повторяйте за мной

### Шаг 1: проверьте подписку Copilot

Проверьте подписку на странице настроек GitHub:

https://github.com/settings/copilot

Вы должны увидеть статус вроде этого:

```
GitHub Copilot
Status: Active
```

Если отображается, что подписки нет, сначала оформите подписку GitHub Copilot.

---

### Шаг 2: начните подключение в OpenCode

Запустите OpenCode:

```bash
opencode
```

В поле ввода введите:

```
/connect
```

Найдите в списке поставщиков `GitHub Copilot` и выберите его.

---

### Шаг 3: завершите авторизацию OAuth

После выбора GitHub Copilot OpenCode покажет ссылку для авторизации:

```
Please visit: https://github.com/login/device
And enter code: XXXX-XXXX
```

**Порядок действий**:

1. Откройте в браузере `https://github.com/login/device`
2. Введите код устройства с экрана (например, `XXXX-XXXX`)
3. Нажмите «Authorize», чтобы авторизовать OpenCode

::: info Автоматическое открытие браузера
Если терминал поддерживает эту функцию, OpenCode автоматически откроет браузер. Если этого не произошло, скопируйте ссылку вручную.
:::

После успешной авторизации OpenCode покажет:

```
✓ Provider added successfully!
```

---

### Шаг 4: выберите модель

После успешного подключения введите:

```
/models
```

Вы увидите модели, доступные через GitHub Copilot:

| Модель | Описание |
|------|------|
| `gpt-4o` | Рекомендуется, флагманская мультимодальная модель |
| `gpt-4o-mini` | Быстрая и недорогая |
| `claude-sonnet-4-5` | Новейшая сбалансированная версия Claude |
| `claude-3-5-haiku` | Быстрая версия Claude |
| `o1` | Модель с улучшенными рассуждениями |
| `o1-mini` | Быстрые рассуждения |

Выберите модель и начните диалог.

::: warning Для некоторых моделей нужна подписка Pro+
Для продвинутых моделей, таких как `o1` и `claude-sonnet-4-5`, может потребоваться GitHub Copilot Pro+. При обычной подписке могут быть доступны только некоторые модели.
:::

---

### Шаг 5: отправьте первую фразу (проверка)

В поле ввода введите:

```
你好，请介绍一下你自己
```

Если вы получили ответ, подключение успешно.

---

## Проверка ✅

- [ ] В `/models` видны модели Copilot
- [ ] После отправки сообщения вы получаете ответ ИИ
- [ ] Нет ошибок (например, `unauthorized` / `subscription required`)

---

## Типичные проблемы

| Симптом | Причина | Решение |
|-----|------|------|
| `unauthorized` | Авторизация OAuth не удалась или истекла | Снова выполните `/connect` и выберите GitHub Copilot |
| `subscription required` | Нет подписки Copilot | Сначала оформите подписку GitHub Copilot |
| Не удаётся найти модель | Недостаточный уровень подписки | Перейдите на Pro+ или выберите другую модель |
| Ошибка на странице авторизации | Истёк код устройства | Снова выполните `/connect` и завершите авторизацию в течение 5 минут |
| Появляется `reauthenticate` | Истёк Token | Пройдите авторизацию заново |

---

## Повторная авторизация

Если Token истёк или возникла проблема с авторизацией, пройдите её заново одним из способов:

**Способ 1: повторное подключение в TUI**

```
/connect
```

Выберите GitHub Copilot и пройдите авторизацию по подсказкам.

**Способ 2: команда в терминале**

```bash
opencode auth login
# 选择 GitHub Copilot
```
