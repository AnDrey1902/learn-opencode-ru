# Подключение DeepSeek (рекомендуемый вариант)

> Примерное время: 5–10 минут

DeepSeek отлично подходит новичкам: прямое подключение в Китае, простая регистрация, очень низкая цена и сильные возможности в программировании.

Если вы ещё не читали, что такое API Key, сначала вернитесь к [обзору 1.4](./04-connect), разберитесь с понятием и продолжайте.

---

## Что вы сможете после урока

- Получить API Key DeepSeek
- Подключить DeepSeek в OpenCode
- Отправить первую фразу и получить ответ

## 🎒 Перед началом

- [ ] Завершить [1.2 Установка](./02-install) и уметь запускать `opencode`
- [ ] Иметь доступ к `https://platform.deepseek.com`

## Повторяйте за мной

### Шаг 1: зарегистрируйте аккаунт DeepSeek

Откройте: https://platform.deepseek.com

Нажмите «Войти/Зарегистрироваться» в правом верхнем углу и зарегистрируйтесь и войдите по номеру телефона или электронной почте.

---

### Шаг 2: получите API Key

Откройте страницу API Keys:
- в левом меню консоли выберите `API Keys`;
- или перейдите напрямую: https://platform.deepseek.com/api_keys

Создайте новый Key и **сразу скопируйте его и сохраните**.

::: warning Показывается только один раз!
На многих платформах Key показывается только один раз. После закрытия окна полный Key больше не будет виден.

Сразу скопируйте его в безопасное место (менеджер паролей или заметки), не отправляйте в чаты, не делайте скриншоты и не публикуйте на GitHub.
:::

---

### Шаг 3: пополните баланс (необязательно, но рекомендуется)

DeepSeek обычно выдаёт новым пользователям небольшую квоту, но она быстро заканчивается. Пополнения примерно на 10 юаней хватит надолго.

---

### Шаг 4: подключите DeepSeek в OpenCode

Запустите OpenCode:

```bash
opencode
```

В поле ввода введите:

```
/connect
```

В списке поставщиков выберите `DeepSeek`, затем вставьте свой API Key.

После успешного подключения откроется экран выбора моделей со списком доступных моделей DeepSeek (например, `deepseek-chat` и `deepseek-reasoner`). Выберите модель и начните диалог.

---

### Шаг 5: отправьте первую фразу (проверка)

В поле ввода введите:

```
你好，请介绍一下你自己
```

Если вы получили ответ, подключение успешно.

::: info 💡 Автоматическое обнаружение переменной окружения
Если в системных переменных окружения уже задан `DEEPSEEK_API_KEY`, OpenCode автоматически обнаружит его при запуске и включит поставщика DeepSeek. Запускать `/connect` или редактировать файл конфигурации не нужно — введите `/models`, чтобы увидеть список моделей DeepSeek.
:::

---

## Проверка ✅

- [ ] После отправки сообщения вы получаете ответ ИИ
- [ ] Нет ошибок (например, `API key invalid` / `insufficient balance` / `connection timeout`)

---

## Типичные проблемы

| Симптом | Причина | Решение |
|-----|------|------|
| `API key invalid` | Key скопирован неправильно или содержит пробелы | Скопируйте его заново и убедитесь, что лишних пробелов нет |
| `insufficient balance` | Недостаточно средств | Пополните баланс в консоли |
| `connection timeout` | Сетевые неполадки | Немного подождите и повторите попытку |
