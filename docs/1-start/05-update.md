# Автообновление: можно не беспокоиться

## Что вы сможете после урока

- Знать, что OpenCode обновляется автоматически (это поведение по умолчанию)
- При необходимости вручную обновлять программу до последней версии
- Понимать, как включить или выключить автообновление

---

## С какими трудностями вы столкнулись

- Вы опасаетесь ошибок или проблем безопасности в старой версии
- Видите уведомление о новой версии, но не знаете, как обновиться
- Хотите использовать последнюю версию, но боитесь проблем после обновления

---

## Когда это пригодится

- **Обычно**: ничего не делать — OpenCode обновится автоматически
- **Особые случаи**: обновить вручную, указать версию или отключить автообновление

## Основная идея

1. **Поведение по умолчанию**: при запуске OpenCode автоматически проверяет и скачивает обновления
2. **Управление настройкой**: через параметр `autoupdate` в файле конфигурации
3. **Ручное обновление**: команда `opencode upgrade`

## Повторяйте за мной

### Важное замечание: этот урок можно пропустить

**Почему?**

Стандартные способы установки OpenCode (`curl | bash` или `brew install`) уже включают **автообновление**. При каждом запуске программа:
1. проверяет новую версию в фоновом режиме;
2. автоматически скачивает обновление;
3. использует новую версию при следующем запуске.

**Для вас это означает**: ничего делать не нужно — программа будет поддерживаться в актуальном состоянии.

**Когда стоит прочитать этот урок?**
- Если вам интересны подробности (из технического любопытства)
- Если нужно вручную установить определённую версию
- Если вы хотите отключить автообновление

---

### Шаг 1: обновление вручную (необязательно)
<AdInArticle />

**Когда нужно обновлять вручную?**

- автообновление не сработало (проблема с сетью);
- вы хотите немедленно перейти на последнюю версию;
- вы хотите установить определённую версию.

**Обновление до последней версии:**

```bash
opencode upgrade
```

**Вы увидите:**

```
┌  Upgrade
│
●  Using method: curl
●  From 1.1.5 → 1.1.6
◇  Upgrading...
│
└  Upgrade complete
```

**Обновление до определённой версии:**

```bash
opencode upgrade 1.1.5
```

Или с префиксом `v`:

```bash
opencode upgrade v1.1.5
```

**Обновление определённым способом установки:**

```bash
opencode upgrade --method npm
```

Поддерживаются способы установки: `curl`, `npm`, `pnpm`, `bun`, `brew`

---

### Шаг 2: настройте автообновление (необязательно)

Автообновлением управляет поле `autoupdate` в файле конфигурации.

**Отредактируйте файл конфигурации:**

**macOS/Linux：**

```bash
# 用你喜欢的编辑器打开
vim ~/.config/opencode/opencode.json
# 或
code ~/.config/opencode/opencode.json
```

**Windows：**

```powershell
notepad $env:USERPROFILE\.config\opencode\opencode.json
```

**Содержимое конфигурации:**

```json
{
  "$schema": "https://opencode.ai/config.json",
  "autoupdate": false
}
```

Три значения:
- `true`: автоматически скачивать обновления (по умолчанию)
- `false`: не проверять обновления
- `"notify"`: уведомлять о новой версии, но не скачивать автоматически

::: tip Переменная окружения
Автообновление также можно отключить переменной окружения:
```bash
export OPENCODE_DISABLE_AUTOUPDATE=true
```
:::

## Типичные проблемы

### Проблема 1: сетевой тайм-аут, скачивание не удалось

**Симптом:**

```
Error: connect ETIMEDOUT
```

**Причина:**
Сеть недоступна или истёк тайм-аут подключения к GitHub

**Решение:**
1. Проверьте сеть
2. Используйте прокси (см. [1.3 Настройка сети](./03-network))
3. Временно отключите автообновление и обновите вручную, когда сеть восстановится

---

### Проблема 2: нужно вернуться к старой версии

**Сценарий:**
В новой версии есть ошибка, и вы хотите вернуться назад

**Решение:**

```bash
opencode upgrade 1.1.5
```

Для отката используется та же команда, что и для обновления — укажите номер старой версии.

---

### Проблема 3: при ручном обновлении появляется «rate limit exceeded»

**Симптом:**

```
error: rate limit exceeded
```

**Причина:**
У GitHub API есть ограничение частоты запросов:
- запросы без аутентификации: 60 в час;
- аутентифицированные запросы: более 2000 в час.

Команда `opencode upgrade` обращается к GitHub API для проверки последней версии. При многократном запуске за короткое время срабатывает ограничение rate limit.

**Варианты решения (3 способа):**

**Способ 1: подождать около часа и повторить попытку**

```bash
# GitHub API 的 rate limit 每小时重置一次
opencode upgrade
```

**Способ 2: указать версию вручную (обойти обращение к API)**

```bash
# 直接指定版本号，不调用 latest() API
opencode upgrade 1.1.6
```

**Способ 3: установить через npm (если есть Node.js)**

```bash
# npm registry 没有 rate limit 限制
npm install -g opencode-ai@latest
```

::: tip Как избежать проблемы
- По возможности используйте автообновление OpenCode и не запускайте `opencode upgrade` вручную слишком часто
- Не выполняйте команду `opencode upgrade` несколько раз за короткий период
:::
