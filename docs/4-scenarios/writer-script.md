# A7 Сценарии (продвинутый уровень)

> 💡 **Коротко**: пишите с AI сценарии в стандартном формате — от синопсиса через поэпизодный план к детальным сценам.

## 📝 Конспект урока

Ключевые идеи урока в сжатом виде:

     data-zoom-src="/images/4-scenarios/writer-script-notes.jpeg" />

<details>
<summary>📝 Текстовая версия шпаргалки</summary>

1. Workflow: синопсис → поэпизодный план → детальные сцены → редактура диалогов.
2. Стандарт формата: описание сцены (жирный, время/место), первое появление героя (возраст/внешность), имя по центру капсом, диалоги с отступом, действия/мимика в скобках.
3. Синопсис: тип, герои, конфликт, финал — 1 предложение; обсуждение в Plan.
4. Разбивка на сцены: номер/место, герои, цель сцены, эмоциональный тон — каждая сцена функциональна.
5. Первая сцена: стандартный формат, визуальные описания, разговорные диалоги с подтекстом, ремарки, сохранить в `scripts/сцена01.md`.
6. Голоса героев: манера речи, присказки, ритм; файл `scripts/голоса.md`.
7. Сборка: `@scripts/голоса.md` → по сценам, каждая в отдельном файле.
8. Ошибки: неверный формат — AI применил формат романа; диалоги длинные — нет лимита; голоса одинаковые — не созданы.

</details>

## Почему OpenCode, а не веб-версия AI?

| Возможность | Веб-версия AI | OpenCode |
|-----|----------|----------|
| Банк сцен | ❌ Каждый раз описываете сцену заново | ✅ Файлы шаблонов сцен, переиспользование через @ |
| Автоформатирование | ❌ Формат часто плывёт | ✅ Формат сценария зафиксирован в AGENTS.md |
| Ведение эпизодов | ❌ Всё в одном файле | ✅ Каждый эпизод — отдельный файл, независимая правка |
| Голоса персонажей | ❌ Реплики смешиваются | ✅ @голоса-персонажей.md держит различия |
| Сравнение версий | ❌ | ✅ Git хранит каждую правку |

## Основная идея

### Процесс написания сценария

```
Синопсис → поэпизодный план → детальные сцены → шлифовка диалогов
```

### Стандартный формат сценария

```
Сцена 1: Интерьер — кафе — день

    Тихий полдень, солнце льётся сквозь витринные стёкла.
    Андрей (30 лет, в повседневном пиджаке) сидит в углу,
    уставившись в экран телефона.

                     АНДРЕЙ
             (про себя)
         Почему её до сих пор нет...

     Звенит колокольчик. Входит Мария (28 лет, собранная, короткая стрижка).

                     МАРИЯ
         Давно ждёшь?

                     АНДРЕЙ
             (поднимаясь)
         Нет, я тоже только пришёл.
```

## Повторите за мной

<AdInArticle />

### Шаг 1: напишите синопсис

**Зачем**
Сценарий начинается с синопсиса — вся история одним абзацем.

Переключитесь в режим Plan:

```
Придумай синопсис 10-минутной короткометражки:
- Жанр: городская мелодрама
- Герои: двое давно не видевшихся однокурсников
- Главный конфликт: давнее недопонимание
- Финал: облегчение и примирение

Сведи всю историю в один абзац
```

### Шаг 2: создайте поэпизодный план

**Зачем**
Разбить историю на сцены и определить функцию каждой.

```
Разбей историю выше на 5–7 сцен, для каждой укажи:
1. Номер и место сцены
2. Действующих лиц
3. Цель сцены (что двигает / что раскрывает)
4. Эмоциональный тон
```

### Шаг 3: напишите первую сцену

**Зачем**
Открывающая сцена решает, будет ли зритель смотреть дальше.

Переключитесь в режим Build:

```
По поэпизодному плану напиши первую сцену в стандартном формате. Требования:
1. Описание сцены — краткое и кинематографичное
2. Диалоги разговорные, с подтекстом
3. Добавь нужные ремарки действий
4. Сохрани в scripts/Сцена01.md
```

### Шаг 4: спроектируйте голоса персонажей

**Зачем**
У каждого героя должна быть узнаваемая манера речи.

```
Спроектируй «голоса» двух главных героев:
- Персонаж A: манера речи, словечки, особенности ритма
- Персонаж B: манера речи, словечки, особенности ритма

Сохрани в scripts/Голоса-персонажей.md
```

### Шаг 5: допишите сценарий целиком

**Зачем**
Проходите сцены по одной до конца.

```
@scripts/Голоса-персонажей.md по поэпизодному плану и характерам голосов допиши сцены 2–5, сохрани каждую в свой файл
```

## 📋 Волшебный промпт

### 📝 Конвертер формата сценария
> Ожидаемый эффект: преобразовать диалог в стандартный формат сценария

````
## Роль
Ты — профессиональный сценарист, в совершенстве знаешь нормы стандартного формата.

## Задача
Преобразовать предоставленный диалог или фрагмент истории в стандартный формат сценария.

## Входные данные
### Обязательные
- Содержание: [вставьте диалог или фрагмент истории]

### Необязательные
- Информация о сцене: 【время/место?】
- Информация о персонажах: 【возраст/внешность?】

## Формат вывода
Выводи в стандартном формате сценария:

```
Сцена N: 【интерьер/натура】 — 【место】 — 【время】

    【Описание сцены: окружение, атмосфера, визуальные элементы】
    【Первое появление персонажа — возраст и краткая внешность】

                    【ИМЯ ПЕРСОНАЖА (по центру, капсом)】
            (ремарка действия/эмоции)
        【Текст реплики, с отступом】

                    【Другой персонаж】
        【Текст реплики】
```

### Нормы формата
1. **Строка сцены**: интерьер/натура, место, время
2. **Описание сцены**: жирным, описывает окружение
3. **Имя персонажа**: по центру, капсом
4. **Ремарка**: в скобках, под именем
5. **Реплика**: под ремаркой, с отступом

## Ограничения
- ✅ Строго держать стандартный формат сценария
- ✅ Первое появление персонажа — с описанием внешности
- ✅ Описания сцен — краткие и кинематографичные
- ❌ Без прозаической повествовательной интонации
- ❌ Без длинных реплик (не больше 3–5 фраз за раз)
````

### 💬 Генератор диалогов
> Ожидаемый эффект: диалоги в характере персонажей

````
## Роль
Ты — опытный сценарист, мастер напряжённых диалогов с подтекстом.

## Задача
По сцене и характерам персонажей создать диалоги в их характере.

## Входные данные
### Обязательные
- Фон сцены: 【описание сцены】
- Персонаж A: 【имя】 — 【черты характера】
- Персонаж B: 【имя】 — 【черты характера】
- Цель диалога: 【чего добиться/что раскрыть】

### Необязательные
- Эмоциональный тон: 【напряжённый/тёплый/давящий?】
- Голоса персонажей: @【файл голосов?】

## Формат вывода
Выводи в стандартном формате диалогов сценария:

```
                    【Персонаж A】
            (действие/эмоция)
        【Реплика】

                    【Персонаж B】
            (действие/эмоция)
        【Реплика】
```

### Требования к диалогам
1. **Различие характеров**: каждый говорит по-своему
2. **Подтекст**: вслух одно, в уме другое
3. **Смена ритма**: то быстро, то медленно, длинные и короткие фразы
4. **Действия в комплекте**: мелкие жесты и мимика во время речи
5. **Напряжение конфликта**: диалог двигает конфликт

## Ограничения
- ✅ Соответствие характеру и манере каждого
- ✅ Каждый круг реплик — в пределах 3–5 фраз
- ✅ Нужные ремарки действий и эмоций
- ❌ Без книжных, письменных реплик
- ❌ Без одинаковой манеры у разных персонажей
````

## Типичные проблемы

| Симптом | Причина | Решение |
|-----|-----|-----|
| Формат не тот | AI пишет прозой | Явно требуйте «стандартный формат сценария» |
| Реплики слишком длинные | Нет лимита на круг диалога | Требуйте «каждому по 3–5 фраз» |
| Персонажи говорят одинаково | Не спроектированы голоса | Сначала определите речевые особенности каждого |
