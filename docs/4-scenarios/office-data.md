<summary>📝 Текстовая версия шпаргалки</summary>

1. Поток: понять структуру → задать цель → выполнить анализ → выдать результат.
2. Инструменты: read (файлы, ≤2000 строк), webfetch (веб, ≤5MB), bash (скрипты, таймаут).
3. Задачи: анализ данных, фильтрация, конвертация (CSV→JSON), отчёты.
4. Структура: `@sales.csv` → строки, столбцы, типы, пустые значения.
5. Базовая статистика: sum/avg/max/min/count, частоты, TOP N.
6. Фильтрация: по условию, комбинация условий, сохранение результата.
7. Отчёты: Markdown-таблицы, графики.
8. Конвертация: CSV→JSON, извлечение полей, экспорт в Excel.
9. Онлайн-данные: webfetch, ≤5MB, следить за стабильностью сети.
10. Ловушки: файл большой — читать кусками; неверные столбцы — проверить имена; webfetch 404 — HTTP/HTTPS; больше 5MB — разбить.

</details>

## Основная идея

### Процесс обработки данных

```
Понять структуру → определить цель анализа → выполнить анализ → выдать результат
```

### Доступные инструменты (в уроке — только возможности OpenCode)

| Инструмент | Назначение | Ключевые параметры и поведение (проверяемо) |
|-----|------|----------------------|
| `read` | Чтение содержимого файлов (с постраничностью) | `offset` (стартовая строка, отсчёт с 0), `limit` (по умолчанию 2000 строк) (исходники: `opencode/packages/opencode/src/tool/read.ts:12`～`opencode/packages/opencode/src/tool/read.ts:21`) |
| `webfetch` | Забор содержимого веб-страниц | `url` только `http/https` (исходники: `opencode/packages/opencode/src/tool/webfetch.ts:21`～`opencode/packages/opencode/src/tool/webfetch.ts:24`); тайм-аут по умолчанию 30 секунд, максимум 120 (исходники: `opencode/packages/opencode/src/tool/webfetch.ts:7`～`opencode/packages/opencode/src/tool/webfetch.ts:9`); лимит размера ответа 5MB (исходники: `opencode/packages/opencode/src/tool/webfetch.ts:6`～`opencode/packages/opencode/src/tool/webfetch.ts:84`) |
| `bash` | Запуск скриптов и команд | `timeout` (миллисекунды, по умолчанию 2 минуты: `opencode/packages/opencode/src/tool/bash.ts:20`～`opencode/packages/opencode/src/tool/bash.ts:80`), `workdir` (рабочий каталог: `opencode/packages/opencode/src/tool/bash.ts:62`～`opencode/packages/opencode/src/tool/bash.ts:67`) |

::: tip Приём
- В TUI запись вида `@sales.csv` подтягивает содержимое файла в контекст (официально: `opencode/packages/web/src/content/docs/tui.mdx:30`～`opencode/packages/web/src/content/docs/tui.mdx:43`).
- Единица `webfetch.timeout` — «секунды» (описание параметра: `opencode/packages/opencode/src/tool/webfetch.ts:18`～`opencode/packages/opencode/src/tool/webfetch.ts:19`).
:::

## Повторите за мной
<AdInArticle />

### Шаг 1: поймите структуру данных

**Зачем**
Сначала посмотреть, как устроены данные.

```bash
cd ~/data  # замените на свой каталог с данными
opencode
```

```
@sales.csv разбери этот CSV-файл:
1. Сколько строк данных (если точно посчитать нельзя — объясни почему и предложи рабочую альтернативу)
2. Какие столбцы (поля)
3. Тип каждого столбца (и на чём основан вывод)
4. Есть ли пустые или аномальные значения
```

### Шаг 2: базовая статистика

**Зачем**
Быстро понять общую картину.

```
@sales.csv сделай статистику продаж:
1. Общая выручка
2. Средний чек
3. Топ-5 товаров по продажам
4. Тренд продаж по месяцам
```

### Шаг 3: фильтрация данных

**Зачем**
Найти записи по условиям.

```
@sales.csv отфильтруй данные:
1. Заказы с суммой больше 1000 рублей
2. Все заказы за январь этого года
3. Заказы клиентов из Москвы

Сохрани результат в filtered_sales.csv
```

### Шаг 4: создайте отчёт

**Зачем**
Свести анализ в читаемый отчёт.

```
@sales.csv создай месячный отчёт о продажах. Содержание:

## Обзор продаж
- Выручка за месяц
- Рост к прошлому месяцу
- Число заказов

## Анализ товаров
- Таблица топ-10 товаров
- Доли категорий

## Анализ регионов
- Рейтинг регионов по выручке

Сохрани в Monthly-report.md
```

### Шаг 5: конвертация форматов

**Зачем**
Разным задачам — разные форматы.

```
@sales.csv выполни конвертацию:
1. В формат JSON, сохрани как sales.json
2. Извлеки данные клиентов, создай customers.csv
3. Создай формат, импортируемый в Excel
```

## Продвинутое: онлайн-данные

### Инструмент webfetch

Кроме локальных файлов можно забирать данные с веб-страниц для анализа:

```
Забери через webfetch веб-страницу (выведи краткое содержание полученного сырого содержимого) и объясни:
1. Что ты получил: text, markdown или html
2. Как превратишь это в анализируемые данные (CSV/JSON/таблица)
```

::: tip Приём
- `webfetch` поддерживает `text` / `markdown` (по умолчанию) / `html` (исходники: `opencode/packages/opencode/src/tool/webfetch.ts:14`～`opencode/packages/opencode/src/tool/webfetch.ts:18`).
- Тайм-аут по умолчанию 30 секунд, максимум 120 (исходники: `opencode/packages/opencode/src/tool/webfetch.ts:7`～`opencode/packages/opencode/src/tool/webfetch.ts:9`).
- Лимит размера ответа 5MB, превышение — ошибка (исходники: `opencode/packages/opencode/src/tool/webfetch.ts:6`～`opencode/packages/opencode/src/tool/webfetch.ts:84`).
:::

### bash: запуск скриптов обработки данных (необязательно)

Если «фильтрацию/чистку/конвертацию» хочется закрепить скриптом (для переиспользования), попросите AI сначала создать скрипт, затем выполните его через `bash`.

::: tip Приём
- Единица `bash.timeout` — миллисекунды, по умолчанию 2 минуты (исходники: `opencode/packages/opencode/src/tool/bash.ts:20`～`opencode/packages/opencode/src/tool/bash.ts:80`).
- Вывод по умолчанию — максимум 30000 символов (исходники: `opencode/packages/opencode/src/tool/bash.ts:19`～`opencode/packages/opencode/src/tool/bash.ts:36`).
:::

## Типичные проблемы

| Симптом | Причина | Решение |
|-----|-----|-----|
| Анализ данных неточен | Файл большой или смотрели фрагмент | Сначала попросите AI описать структуру + выборку, затем анализируйте всё целиком (при необходимости постранично через `read.offset/limit`) |
| Ошибки в расчётах | Неверно поняты имена столбцов или единицы | Сначала попросите AI пересказать смысл столбцов и единицы, затем считать |
| `webfetch` ругается на URL | URL не http/https | Проверьте протокол ссылки (исходники: `opencode/packages/opencode/src/tool/webfetch.ts:21`～`opencode/packages/opencode/src/tool/webfetch.ts:24`) |
| `webfetch` ругается на размер | Превышен лимит 5MB | Возьмите страницу или API поменьше, либо забирайте по частям (исходники: `opencode/packages/opencode/src/tool/webfetch.ts:6`～`opencode/packages/opencode/src/tool/webfetch.ts:84`) |
