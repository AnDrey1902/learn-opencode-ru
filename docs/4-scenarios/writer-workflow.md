> 💡 **Коротко**: придумывайте структуру в режиме Plan, выпускайте контент в режиме Build.

<summary>📝 Текстовая версия шпаргалки</summary>

2. Plan — обсуждение темы и структуры, без создания файлов.
3. Build-выпуск — генерация контента и файлов; Build-итерация — доработка и шлифовка.
4. Переключение режимов — Tab.
5. Workflow из 4 шагов: Plan-задумка → обсуждение → Build-выпуск → Build-итерация.
6. Принцип: сначала продумать, потом писать — меньше переделок.
7. Приёмы итераций: @имя_файла для ссылок, опора на план.
8. Ошибки: нет задумки — бессвязный текст; нет плана — хаос; стиль плывёт.

## Основная идея

### Три этапа письма с AI

| Этап | Режим | Что делаем |
|-----|------|-------|
| Задумка | Plan | Формулируем тему, утверждаем структуру, пишем план |
| Выпуск | Build | Генерируем готовый контент, создаём файлы |
| Итерации | Build | Правим, шлифуем, расширяем |

### Зачем делить на этапы

- **На этапе задумки файлы не пишем**: чтобы не плодить полуфабрикаты
- **Сначала думаем, потом делаем**: меньше переделок
- **Итерации по плану**: правим отталкиваясь от структуры, не уходим в сторону

## Повторите за мной
<AdInArticle />

### Шаг 1: создайте папку писательского проекта

**Зачем**
Держать весь писательский контент в одном месте.

```bash
mkdir ~/my-writing
cd ~/my-writing
opencode
```

### Шаг 2: переключитесь в Plan и придумайте структуру

**Зачем**
На этапе задумки нужно только обсуждение — файлы создавать не надо.

Нажмите <kbd>Tab</kbd>, чтобы в строке состояния был `Plan`.

Введите:

```
Хочу написать статью «Плюсы и минусы удалённой работы» для молодых специалистов, объём около 800 слов. Помоги мне:
1. Определить структуру статьи
2. Перечислить тезисы каждого раздела
3. Предложить цепляющий заголовок
```

**Вы должны увидеть**: AI выдаст структуру и план статьи, но не создаст ни одного файла

### Шаг 3: обсудите и доработайте план

**Зачем**
Зафиксировать направление до начала письма.

Опираясь на предложения AI, продолжите обсуждение:

```
В раздел «Минусы удалёнки» можно добавить пример из личного опыта? Обнови план
```

### Шаг 4: переключитесь в Build и выпустите текст

**Зачем**
План утверждён — генерируем готовый контент.

Нажмите <kbd>Tab</kbd> для перехода в режим `Build`.

Введите:

```
По обсуждённому плану напиши полную статью и сохрани в файл Плюсы и минусы удалёнки.md
```

**Вы должны увидеть**: AI создаст файл и запишет полную статью

### Шаг 5: итерируйте правки

**Зачем**
Черновик обычно требует доводки.

Продолжайте править в режиме Build:

```
@Плюсы и минусы удалёнки.md начало слишком плоское, открой текст захватывающим описанием сцены
```

**Вы должны увидеть**: AI перепишет начало файла

## 📋 Волшебный промпт

### ✍️ Стартовый шаблон для текста
> Ожидаемый эффект: готовые структура и план статьи — фундамент дальнейшей работы

```
## Роль
Ты — опытный контент-стратег, мастер структурного мышления и планирования контента.

## Задача
По заданной теме создать полные структуру и план статьи.

## Входные данные
### Обязательные
- Тема статьи: 【тема】
- Целевая аудитория: 【портрет читателя】

### Необязательные
- Цель статьи: 【убедить/просветить/развлечь/обучить?】 (по умолчанию: просветить)
- Требуемый объём: 【число слов】 (по умолчанию: 12000+ слов)
- Тон и стиль: 【строгий/лёгкий с юмором/тёплый?】 (по умолчанию: лёгкий с юмором)

## Формат вывода
1. **Позиционирование статьи**
   - Главная мысль (одним предложением)
   - Боли и потребности целевой аудитории
   - Что получит прочитавший

2. **Структура статьи**
   | Раздел | Функция | Примерный объём |
   |------|------|----------|
   | Начало | Зацепить внимание | xxx слов |
   | Середина | Основной контент | xxx слов |
   | Концовка | Призыв к действию | xxx слов |

3. **Тезисы каждого раздела**
   - Начало: как войти в тему
   - Середина: главные тезисы + supporting-материалы
   - Концовка: вывод + запоминающаяся фраза

4. **Запасные заголовки** (3 штуки)
   - Заголовок 1
   - Заголовок 2
   - Заголовок 3

## Ограничения
- ✅ Структура чёткая, функция каждого раздела ясна
- ✅ Тезисы конкретные, а не просто «рассказать полезное»
- ✅ Учитывай опыт чтения и кривую внимания аудитории
- ❌ Не усложняй структуру
- ❌ Не делай тезисы слишком общими
```

## Типичные проблемы

| Симптом | Причина | Решение |
|-----|-----|-----|
| AI сразу вывалил кучу текста без структуры | Не было этапа задумки | Сначала обсудите план в режиме Plan |
| Правки делают только хуже | Итерации без опоры на план | Вернитесь к плану, уточните, что менять |
| Стиль плавает | Каждый раз заново описываете стиль | Зафиксируйте стилевые предпочтения в AGENTS.md |
