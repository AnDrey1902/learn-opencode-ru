## Основная идея

### Модель AIDA

| Этап | Английский | Смысл | Роль в тексте |
|-----|------|------|---------|
| A | Attention | Внимание | Заголовок цепляет глаз |
| I | Interest | Интерес | Боль отзывается |
| D | Desire | Желание | Выгоды разжигают желание |
| A | Action | Действие | CTA ведёт к конверсии |

### Типы текстов: краткий обзор

| Тип | Особенности | Объём |
|-----|------|------|
| Пост для соцсетей | Коротко и быстро, с картинкой | 50–150 знаков |
| Статья для блога | История, глубина | 1000–3000 знаков |
| Карточка товара | Структурно, упор на преимущества | 2000+–12000+ знаков |
| Слоган | Максимально коротко, запоминается | 5–20 знаков |

## Повторите за мной

### Шаг 1: разберите преимущества продукта

**Зачем**
Хороший текст начинается с понимания продукта.

Переключитесь в режим Plan:

```
Продвигаю «умные наушники с шумоподавлением», цена 599 юаней.
Помоги разобрать:
1. Портрет целевой аудитории (возраст, профессия, боли)
2. Главные преимущества (3 штуки)
3. Отличия от конкурентов
4. Возможные сомнения покупателей и как их снять
```

### Шаг 2: сгенерируйте цепляющие заголовки

**Зачем**
Заголовок решает 80% кликабельности.

```
Сгенерируй 10 заголовков для этих наушников. Требования:
1. Используй цифры (например, «3 причины»)
2. Интригуй (например, «Оказывается...»)
3. Бей в боль (например, «Достал шум?»)
4. Показывай результат (например, «Продуктивность +50%»)

Каждого типа минимум 2–3 штуки
```

### Шаг 3: напишите текст по структуре AIDA

<AdInArticle />

**Зачем**
Структурированный текст убедительнее.

Переключитесь в режим Build:

```
Напиши по модели AIDA пост для соцсетей (до 150 знаков):

【Attention】Первая фраза цепляет внимание
【Interest】Опиши боль пользователя
【Desire】Покажи, как продукт решает её
【Action】Промо-информация + призыв к действию

Сохрани в copy/пост-для-соцсетей.md
```

### Шаг 4: создайте A/B-варианты

**Зачем**
Тест нескольких версий находит лучшую.

```
На основе текста выше создай 3 версии:
- Версия A: упор на ощущение «тишины»
- Версия B: упор на «выгодную цену»
- Версия C: упор на «выбор профессионалов»

Сохрани в copy/AB-версии.md
```

### Шаг 5: полный комплект текстов

**Зачем**
За раз — материалы для всех каналов.

```
Создай для этих наушников полный комплект текстов:
1. Слоган (до 10 знаков)
2. Пост для соцсетей (150 знаков)
3. Заметка для Xiaohongshu (300 знаков + 5 хештегов)
4. Текст карточки товара (800 знаков, с разбивкой преимуществ)

Всё сохрани в каталог copy/
```

【CTA-текст】
