# A2 Публичные аккаунты WeChat

> 💡 **Коротко**: постройте с OpenCode контентный конвейер для публичных аккаунтов — пакетные темы, ведение серий, закреплённый стиль.

## 📝 Конспект урока

Ключевые идеи урока в сжатом виде:

<img src="/images/4-scenarios/writer-wechat-notes.mini.jpeg"
     alt="Шпаргалка урока: A2 Публичные аккаунты WeChat"
     data-zoom-src="/images/4-scenarios/writer-wechat-notes.jpeg" />

<details>
<summary>📝 Текстовая версия шпаргалки</summary>

1. Структура проекта: банк тем/, банк материалов/, статьи/ (по сериям), гайд по стилю.md.
2. Стиль фиксируется один раз в файле агента `.opencode/agent/novelist.md`.
3. Контент-календарь сразу на 30 дней.
4. Поля плана: заголовок, главная мысль, целевые ключи, сложность.
5. Серии: план серии → 01-xxx.md → 02-xxx.md, управление едино.
6. Библиотеки материалов (цитаты, кейсы, данные) подключаются через @ при написании.
7. Позиционирование: карьерный рост, аудитория 25–35 лет.
8. Ошибки: стиль плывёт — не зафиксирован; материалы теряются — нет учёта; серия хаотична — нет плана.

</details>

## Почему OpenCode, а не веб-версия AI?

| Возможность | Веб-версия AI | OpenCode |
|-----|----------|----------|
| Пакетный подбор тем | ❌ Только копипаст | ✅ За раз, сразу в файл |
| Консистентность стиля | ❌ Каждый раз описываете заново | ✅ AGENTS.md фиксирует навсегда |
| Ведение серий статей | ❌ Много файлов не ведёт | ✅ Структура каталогов: планы и главы раздельно |
| Вызов банка материалов | ❌ Локальные файлы не читает | ✅ Ссылки @материалы на прошлый контент |
| Трекинг версий | ❌ | ✅ Git хранит историю творчества |

## Повторите за мной

### Шаг 1: создайте структуру проекта публичного аккаунта

**Зачем**
Держать весь контент централизованно, а не разбросанным.

```bash
mkdir ~/my-wechat
cd ~/my-wechat
opencode
```

Попросите AI построить структуру каталогов:

```
Создай структуру каталогов для ведения контента публичного аккаунта:
- банк-тем/ (хранить планирование тем)
- банк-материалов/ (переиспользуемые материалы)
- статьи/ (по сериям, подкаталоги)
- гид-по-стилю.md (описание стиля письма)

Создай эти каталоги и пустые файлы
```

### Шаг 2: зафиксируйте стиль письма в Agent

**Зачем**
Написать один раз — работает всегда, не нужно повторять описание.

Конфиг Agent кладётся в два места:
- **Глобально**: `~/.config/opencode/agent/` — общий для всех проектов
- **На уровне проекта**: `.opencode/agent/` — только для текущего проекта

Имя файла и есть имя Agent, например `novelist.md` (а не `novelist/novelist.md`)

```
Создай писательский Agent и сохрани в .opencode/agent/novelist.md со следующим содержанием:

---
name: novelist
description: Профессиональный помощник автора романов: придумывает сюжеты, проектирует персонажей, шлифует текст
mode: subagent
temperature: 0.8
---

Позиционирование аккаунта: карьерный рост
Целевая аудитория: офисные сотрудники 25–35 лет
Тон: профессионально, но без чванства, как разговор с другом
Структура статьи: зачин с вопросом → середина с пользой → концовка с золотой фразой
Запрещённые слова: синергия, бери и делай, воронка, трекинг, гранулярность
Объём: 12000+–22000+ знаков
```

**Вы должны увидеть**: AI создал файл конфигурации Agent

::: tip 💡 В этом уникальная ценность OpenCode
С этого момента каждая статья будет автоматически следовать стилю — описывать его заново не нужно.
:::

### Шаг 3: пакетно создайте календарь тем
<AdInArticle />

**Зачем**
Раз спланировать месяц — избавиться от ежедневной тревоги «о чём писать».

```
По моему позиционированию (карьерный рост) создай календарь тем на будущие 30 дней:

Требования:
1. По 3 статьи в неделю, всего 12
2. Включить: заголовок, главную мысль, целевые ключевые слова
3. Учесть привязку к инфоповодам (итоги года, планы на новый год)
4. Пометить сложность (простая/средняя/глубокая)

Сохрани в банк-тем/темы-на-январь-2025.md
```

### Шаг 4: постройте структуру серии статей

**Зачем**
Серии статей растят лояльность подписчиков, но требуют единого управления.

```
Хочу написать серию «Деловая коммуникация» из 5 статей.

Помоги мне:
1. Создать каталог статьи/серия-деловой-коммуникации/
2. Создать план.md (план серии, позиционирование каждой, порядок выхода)
3. Создать пустые файлы для каждой (формат 01-xxx.md)

План серии:
- Статья 1: почему ваша коммуникация вечно неэффективна
- Статья 2: 3 приёма общения с руководством
- Статья 3: главный принцип межотдельной коммуникации
- Статья 4: как начинать сложные разговоры
- Статья 5: личный бренд через коммуникацию
```

### Шаг 5: создавайте статьи с вызовом материалов

**Зачем**
Переиспользуйте готовые материалы — быстрее.

Сначала добавьте материалов:

```
Создай в банк-материалов/ следующие файлы:

банк-золотых-фраз.md — собранные карьерные афоризмы
банк-кейсов.md — реальные рабочие кейсы
банк-данных.md — исследования и статистика
```

Затем пишите статью на материалах:

```
По теме «3 приёма общения с руководством» напиши статью для публичного аккаунта.

Требования:
1. Следуй стилю из AGENTS.md
2. Сошлись на золотые фразы из @банк-материалов/банк-золотых-фраз.md
3. Используй кейсы из @банк-материалов/банк-кейсов.md
4. Объём около 2000 знаков

Сохрани в статьи/серия-деловой-коммуникации/02-три-приёма-общения-с-руководством.md
```

## 📋 Волшебный промпт

### 📅 Планирование тем на 30 дней
> Ожидаемый эффект: готовый календарь тем — месяц спланирован за раз

```
## Роль
Ты — опытный контент-оператор: мастер планирования тем и контент-календарей.

## Задача
По позиционированию аккаунта создать календарь тем на будущие 30 дней.

## Входные данные
### Обязательные
- Позиционирование аккаунта: 【сфера】
- Целевая аудитория: 【портрет читателей】
- Частота выхода: 【N】 статей в неделю

### Необязательные
- Свежие инфоповоды: 【к чему привязаться?】
- Прошлые темы: 【что уже выходило?】

## Формат вывода
Создай таблицу тем:
| Дата | Заголовок темы | Главная мысль | Целевые ключевые слова | Сложность | Тип |
|------|---------|---------|-----------|------|------|

### Пометки сложности
- Простая (30 минут)
- Средняя (1 час)
- Глубокая (2 часа)

### Пометки типов
- Польза: практические приёмы, методологии
- История: кейсы, личный опыт
- Мнение: комментарии, размышления
- Подборка: сводки, рейтинги

## Ограничения
- ✅ У каждой темы главная мысль, а не только заголовок
- ✅ Учитывай актуальность (праздники, сезоны, инфоповоды)
- ✅ Разнообразие сложности и типов
- ❌ Темы не должны быть однообразными
- ❌ Без повторов уже выходившего
```

### 🎨 Шаблон закрепления стиля
> Ожидаемый эффект: конфиг Agent, фиксирующий стиль аккаунта

````
## Роль
Ты — бренд-стратег: умеешь определять и закреплять образ аккаунта.

## Задача
Создать конфиг стиля письма для публичного аккаунта (AGENTS.md).

## Входные данные
### Обязательные
- Название аккаунта: 【название аккаунта】
- Сфера: 【сфера】
- Целевая аудитория: 【возраст, профессия, боли】

### Необязательные
- Тон: 【например «профессионально, но тепло»?】
- Аккаунты-референсы: 【на чей стиль ориентироваться?】

## Формат вывода
Создай конфиг AGENTS.md:

```yaml
---
name: 【имя аккаунта】
description: 【описание одной фразой】
---

## Позиционирование аккаунта
【описание позиционирования】

## Портрет целевой аудитории
- Возраст:
- Профессия:
- Боли:
- Потребности:

## Тон
【подробное описание с хорошими и плохими примерами】

## Шаблон структуры статьи
1. Зачин: 【как входить】
2. Середина: 【структура главной части】
3. Концовка: 【как завершать】

## Запрещённые слова
【нежелательные слова через запятую】

## Фирменные обороты
【примеры оборотов в личном стиле】

## Объём
【число знаков】
```

## Ограничения
- ✅ Описание стиля конкретное, с хорошими и плохими примерами
- ✅ Запрещённые слова — реально рабочие
- ✅ Структура статьи — переиспользуемая
- ❌ Без слишком общих формулировок
````

### 📚 Планирование серий статей
> Ожидаемый эффект: структура серии, связный контент

````
## Роль
Ты — контент-архитектор: мастер планирования серийного контента.

## Задача
Спроектировать общую структуру серии и позиционирование каждой статьи.

## Входные данные
### Обязательные
- Тема серии: 【тема】
- Число статей: 【N】 штук
- Цель серии: 【что получит читатель】

### Необязательные
- Целевая аудитория: 【портрет читателей?】
- Периодичность: 【сколько статей в неделю?】

## Формат вывода
1. **Обзор серии**
   - Позиционирование серии
   - Целевая аудитория
   - Главная ценность

2. **План статей**
   | № | Заголовок | Главное содержание | Связь с прошлой | Связь со следующей |
   |------|------|---------|-----------|-----------|

3. **Логика нарастания**
   - От 【старта】 к 【финишу】
   - Связи статей между собой

4. **Структура каталогов**
   ```
   название-серии/
   ├── план.md
   ├── 01-xxx.md
   ├── 02-xxx.md
   └── ...
   ```

## Ограничения
- ✅ Каждая статья ценна сама по себе и стыкуется с соседними
- ✅ Логика нарастания ясная
- ✅ Учитывай кривую обучения читателя
- ❌ Без пересечений содержания
- ❌ Без слишком резких скачков
````

## Типичные проблемы

| Симптом | Причина | Решение |
|-----|-----|-----|
| AI пишет каждый раз в разном стиле | Стиль не зафиксирован в AGENTS.md | Запишите требования к стилю в AGENTS.md |

| Логика серии статей хромает | Сначала не написан план | Создайте план-серии.md |

## Продвинутые приёмы

### Создание быстрой команды

Частые действия оформите слэш-командой:

```bash
mkdir -p .opencode/command
```

Создайте `.opencode/command/wechat.md`:

```markdown
---
description: Быстрое создание статьи для публичного аккаунта
---

Напиши статью для публичного аккаунта по теме:

Тема: $ARGUMENTS

Требования:
1. Следуй стилю из AGENTS.md
2. Сошлись на релевантные материалы из @банк-материалов/
3. Объём около 2000 знаков
4. Сохрани в каталог статьи/
```

После этого достаточно ввести `/wechat Приёмы общения с руководством`, и статья готова.
