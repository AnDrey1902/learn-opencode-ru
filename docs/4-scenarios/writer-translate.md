# A5 Перевод и редактура

> 💡 **Коротко**: перевод, редактура и рерайтинг с AI при единой терминологии.

## 📝 Конспект урока

Ключевые идеи урока в сжатом виде:

<details>
<summary>📝 Текстовая версия шпаргалки</summary>

1. Workflow: глоссарий → посегментный перевод → унификация терминов → вычитка.
2. Разграничение: перевод (между языками), редактура (читаемость), рерайтинг (антиплагиат).
3. Глоссарий `glossary.md` с парами терминов (например, Neural Network → «нейросеть»).
4. Перевод по сегментам (~500 знаков): сегмент → `@glossary.md` → перевод → проверка терминов.
5. Редактура: грамматика, академический стиль, единообразие терминов.
6. Антиплагиат: смысл + синонимы + перестройка предложений → 3 версии на выбор.
7. Ошибки: термины плывут — нет глоссария; качество падает — слишком длинные сегменты; смысл потерян — слишком агрессивные правки.

</details>

---

## Почему OpenCode, а не веб-версия AI?

| Возможность | Веб-версия AI | OpenCode |
|-----|----------|----------|
| Пакетный перевод | ❌ Копипаст по абзацам | ✅ Пакетная обработка файлов с сохранением формата |
| Единство терминов | ❌ Каждый раз переводит по-разному | ✅ Ссылка @глоссарий — единый перевод всего текста |
| Длинные тексты | ❌ Легко упереться в лимит контекста | ✅ Перевод по частям с автосборкой |
| Сохранение формата | ❌ Формат часто теряется | ✅ Прямая правка файлов, формат цел |
| Сравнение версий | ❌ | ✅ Git хранит историю правок перевода |

## Основная идея

### Рабочий процесс перевода

```
Подготовка глоссария → перевод по частям → унификация терминов → сквозная редактура
```

### Перевод vs редактура vs рерайтинг

| Задача | Цель | Типичный кейс |
|-----|------|---------|
| Перевод | Перенос между языками | Английскую статью — на китайский |
| Редактура | Качество изложения | Улучшить читаемость текста |
| Рерайтинг | Те же смыслы другими словами | Антиплагиат, вторичный контент |

## Повторите за мной

<AdInArticle />

### Шаг 1: подготовьте глоссарий

**Зачем**
Единая терминология — ключ профессионального перевода.

Переключитесь в режим Build:

```
Перевожу англоязычную статью по машинному обучению.
Создай глоссарий с русскими соответствиями частых терминов:
- Neural Network
- Deep Learning
- Gradient Descent
- Overfitting
- Regularization

Сохрани в glossary.md
```

### Шаг 2: переводите по частям

**Зачем**
Длинный текст по частям переводится качественнее.

```
@glossary.md

Переведи английский абзац ниже. Требования:
1. Используй нормативные соответствия из глоссария
2. Держи академический стиль
3. Предложения — гладкие и естественные

Исходник:
{вставьте английский абзац}
```

### Шаг 3: перевод целиком

**Зачем**
Небольшие файлы можно перевести за раз.

```
@glossary.md @paper.txt

Переведи paper.txt на китайский. Требования:
1. Нормативные соответствия из глоссария
2. Сохрани структуру абзацев оригинала
3. Сохрани как paper_cn.md
```

### Шаг 4: отредактируйте для читаемости

**Зачем**
После перевода текст обычно нужно причесать.

```
@paper_cn.md

Отредактируй этот перевод. Требования:
1. Исправь корявые предложения
2. Сохрани академическую строгость, но подними читаемость
3. Проверь единство терминов
4. Правь исходный файл напрямую
```

### Шаг 5: рерайтинг для уникальности

**Зачем**
Иногда нужно снизить процент совпадений.

```
Сделай рерайтинг абзаца ниже. Требования:
1. Смысл сохранить
2. Переписать другими выражениями
3. Выдать 3 версии на выбор

Исходник:
{вставьте абзац для рерайтинга}
```

## 📋 Волшебный промпт

### 🌐 Профессиональный перевод
> Ожидаемый эффект: качественный перевод с единой терминологией

```
## Роль
Ты — профессиональный переводчик: сохраняешь смысл и делаешь перевод естественным.

## Задача
Перевести предоставленный текст на целевой язык.

## Входные данные
### Обязательные
- Целевой язык: 【упрощённый китайский/английский/японский/...】
- Исходник:

[вставьте исходник]

### Необязательные
- Глоссарий: @【файл глоссария?】
- Предметная область: 【техника/право/медицина/художественный текст?】
- Тон и стиль: 【официальный/лёгкий/профессиональный?】

## Требования к переводу
1. **Единство терминов**: нормативные соответствия из глоссария
2. **Сохранение формата**: абзацы, заголовки и списки оригинала
3. **Естественность**: не переводи дословно, перевод должен читаться гладко
4. **Имена собственные**: при первом появлении после перевода дай оригинал в скобках (например: Machine Learning («машинное обучение»))

## Формат вывода
### Перевод
[результат перевода]

### Комментарии к переводу (при наличии)
- Многозначность: 【слово】 переведено как 【вариант】, потому что 【причина】
- Подтверждение термина: 【термин】 — 【вариант】, по глоссарию

## Ограничения
- ✅ Термины едины по всему тексту (один термин — один перевод)
- ✅ Читаемость важнее дословной точности
- ✅ Профессиональные термины — по стандартам области
- ❌ Без переводческого канцелярита (вроде «осуществлять», «в целях», «данный»)
- ❌ Без пропусков содержания оригинала

## Обработка ошибок
- Целевой язык не указан — сначала спроси пользователя
- Многозначное слово — отметь возможные варианты на выбор
- Термина нет в глоссарии — используй общий перевод и пометь
```

### ✏️ Рерайтинг для уникальности
> Ожидаемый эффект: несколько версий с тем же смыслом, ниже процент совпадений

```
## Роль
Ты — профессиональный редактор: сохраняешь смысл и меняешь форму изложения.

## Задача
Переписать предоставленный текст, снизив схожесть с оригиналом.

## Входные данные
### Обязательные
- Глубина рерайтинга: 【лёгкая (30%)/средняя (50%)/глубокая (70%)】
- Исходник:

[вставьте исходник]

### Необязательные
- Сохранить ключевые слова: 【какие термины нельзя трогать?】
- Требования к стилю: 【академический/популярный/официальный?】

## Стратегии рерайтинга
### Лёгкий (~30%)
- Замена синонимами
- Небольшие перестановки
- Ядро изложения сохраняется

### Средний (~50%)
- Смена синтаксических конструкций
- Актив ↔ пассив
- Объединение/разбиение предложений

### Глубокий (~70%)
- Перестройка логики абзацев
- Те же мысли другими словами
- Добавление/удаление деталей

## Формат вывода
### Версия 1
[переписанный текст]

### Версия 2
[переписанный иначе]

### Версия 3
[третий вариант]

---

### Статистика рерайтинга
| Версия | Оценка глубины | Главный приём |
|------|-------------|-------------|
| Версия 1 | X% | 【приём】 |
| Версия 2 | X% | 【приём】 |
| Версия 3 | X% | 【приём】 |

**Рекомендую**: версия 【N】
**Почему**: 【причина】

## Ограничения
- ✅ Смысл неизменен
- ✅ Профессиональные термины точны
- ✅ Версии заметно различаются
- ❌ Не менять главную мысль
- ❌ Не добавлять того, чего нет в оригинале
```

## Типичные проблемы

| Симптом | Причина | Решение |
|-----|-----|-----|
| Термины плавают | Нет глоссария | Сначала создайте глоссарий, при переводе ссылайтесь через @ |
| Качество длинного перевода падает | Слишком большой кусок за раз | Переводите по частям, каждый кусок — от 2000+ знаков |
| После рерайтинга смысл поплыл | Слишком агрессивные правки | Требуйте «сохранить исходный смысл» |
