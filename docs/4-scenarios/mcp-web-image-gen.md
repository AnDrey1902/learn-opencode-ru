# Автоматизация веб-рисования через MCP

> **Коротко**: пусть AI управляет браузером — рисует в Jimeng и Gemini автоматически и скачивает локально.

---

## Что вы сможете после урока

- Автоматически открывать с AI веб-версии Jimeng и Gemini
- Автоматически вводить промпты и генерировать картинки
- Автоматически скачивать картинки в указанный локальный каталог
- Генерировать и скачивать пакетно, без ручных действий

---

## С какими трудностями вы столкнулись

- Хотите генерировать пакетно, а веб-версия — по одному клику
- Скачивание — вручную через «сохранить как», медленно
- У API-версий то нет квоты, то надо платить
- Готовые веб-инструменты есть, а автоматизировать их нечем

---

## Когда это пригодится

- Когда нужно: пакетно генерировать картинки без ручной работы
- И не хочется: отдельно подключать API каждой рисовалки
- Особенно: вы уже пользуетесь веб-версией и хотите её автоматизировать

---

## Основная идея

```
┌─────────────────────────────────────────────────────────────┐
│                 Процесс автоматизации веб-рисования           │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ┌─────────┐    ┌─────────────┐    ┌─────────────┐         │
│  │ Открыть │ →  │ Ввести      │ →  │ Подождать   │         │
│  │ страницу│    │ промпт      │    │ генерацию   │         │
│  └─────────┘    └─────────────┘    └─────────────┘         │
│                                          │                  │
│                                          ▼                  │
│  ┌─────────────┐    ┌─────────────┐    ┌─────────────┐     │
│  │ Сохранить   │ ←  │ Нажать      │ ←  │ Найти       │     │
│  │ локально    │    │ «Скачать»   │    │ картинку    │     │
│  └─────────────┘    └─────────────┘    └─────────────┘     │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

Главное:
1. **MCP управляет браузером** — API не нужен, действия прямо на странице
2. **Дождаться генерации** — через `wait_for` ждём появления нужного текста
3. **Автоскачивание** — клик по кнопке скачивания, браузер сохраняет сам

## Сценарий 1: рисование в Jimeng

### Шаг 1: откройте страницу Jimeng

**Зачем**
Пусть MCP откроет новую страницу и перейдёт на страницу генерации Jimeng.

Скажите AI напрямую:

```
Открой Jimeng AI, адрес https://jimeng.jianying.com
```

AI вызовет инструмент `chrome-devtools_new_page` и откроет страницу.

**Вы должны увидеть**: новая вкладка браузера, главная страница Jimeng.

### Шаг 2: перейдите в режим генерации картинок

**Зачем**
У Jimeng несколько функций (видео, картинки, цифровые люди и т. д.) — нужен модуль генерации картинок.

AI:
1. Снимет снепшот страницы (`take_snapshot`)
2. Найдёт кнопку «Генерация картинок»
3. Нажмёт и перейдёт

**Вы должны увидеть**: переход на страницу генерации, поле ввода на месте.

### Шаг 3: введите промпт

**Зачем**
Сказать AI, что нарисовать.

```
Введи промпт: эпичная битва космического героя и царя обезьян из восточной мифологии, кинематографичные эффекты
```

AI вызовет инструмент `fill` и впишет текст в поле ввода.

::: warning Про стоп-слова
В Jimeng есть модерация контента: «Ультрамен» и «Сунь Укун» напрямую могут блокироваться.

Обходные формулировки:
- Ультрамен → космический герой, гигант света
- Сунь Укун → царь обезьян из восточной мифологии, Великий Мудрец
:::

### Шаг 4: нажмите «Создать» и ждите

**Зачем**
Запустить генерацию и дождаться готовности картинки.

AI:
1. Нажмёт кнопку генерации
2. Через `wait_for` дождётся появления слов «Скачать», «Готово» и т. п.

**Время ожидания**: обычно 30–60 секунд, зависит от нагрузки серверов.

### Шаг 5: скачайте картинку локально

**Зачем**
Сохранить созданное на свой компьютер.

AI:
1. Нажмёт на картинку для предпросмотра
2. Найдёт кнопку «Скачать»
3. Нажмёт скачать

Картинка сохранится в каталог загрузок браузера по умолчанию:
- macOS: `~/Downloads/`
- Windows: `C:\Users\ваше-имя\Downloads\`
- Linux: `~/Downloads/`

### Полный пример диалога с Jimeng

```
Вы: открой Jimeng, нарисуй «древнюю городскую стену в стиле киберпанк», скачай на рабочий стол

AI:
1. Открываю https://jimeng.jianying.com/ai-tool/generate
2. Ввожу промпт
3. Нажимаю «Создать»
4. Жду готовности (около 45 секунд)
5. Нажимаю «Скачать»
6. Картинка сохранена в ~/Downloads/jimeng-xxx.png
```

### Частые проблемы Jimeng

| Проблема | Причина | Решение |
|-----|-----|-----|
| Промпт заблокирован | Фильтр стоп-слов | Описательные обходы, например «космический герой» вместо «Ультрамена» |
| Скачивание не реагирует | При первом скачивании всплывает настройка вотермарка | AI обработает сам, или вручную нажмите «Сохранить настройки» |
| Генерация медленная | Высокая нагрузка серверов | Подождите, можно открыть несколько сессий параллельно |

## Сценарий 2: рисование в Gemini

### Шаг 1: откройте Gemini

```
Открой Gemini, адрес https://gemini.google.com/app
```

**Вы должны увидеть**: интерфейс чата Gemini с полем ввода.

### Шаг 2: введите промпт для рисования

```
Нарисуй красное яблоко, фотореалистично, с глянцевым блеском
```

Gemini сам распознает запрос на рисование и вызовет встроенную генерацию изображений.

### Шаг 3: дождитесь готовности

AI через `wait_for` ждёт появления кнопок «Скачать», «Копировать» и т. п.

**Время ожидания**: обычно 15–30 секунд.

### Шаг 4: скачайте картинку

После генерации у картинки будет несколько кнопок:
- Поделиться картинкой
- Копировать картинку
- **Скачать картинку в полном размере** ← нажать сюда

AI нажмёт кнопку скачивания, картинка сохранится в каталог загрузок.

### Полный пример диалога с Gemini

```
Вы: открой Gemini, нарисуй «маяк на берегу моря на закате», скачай локально

AI:
1. Открываю https://gemini.google.com/app
2. Ввожу: нарисуй маяк на берегу моря на закате
3. Жду генерации (около 20 секунд)
4. Нажимаю «Скачать картинку в полном размере»
5. Картинка сохранена в ~/Downloads/
```

### Сравнение Gemini и Jimeng

| Критерий | Gemini | Jimeng |
|-------|-------|-----|
| Доступ | Нужен VPN | Прямой доступ из России и Китая |
| Скорость генерации | Быстрее (15–30 секунд) | Медленнее (30–60 секунд) |
| Модерация контента | Относительно мягкая | Строже (блокировка стоп-слов) |
| Число картинок | Обычно 1 | Обычно 4 |
| Способ скачивания | Прямое скачивание | Нужно обработать вотермарк |

## Продвинутое: пакетная генерация

### Пакетная генерация нескольких картинок

```
Сгенерируй следующие 5 картинок, все скачай в папку images на рабочем столе:

1. Улица в стиле киберпанк
2. Горы и воды в стиле китайской живописи
3. Милый котёнок в мультяшном стиле
4. Чашка кофе, фотореалистично
5. Космос в абстрактном стиле
```

AI по очереди:
1. Откроет сайт рисовалки
2. Введёт каждый промпт
3. Дождётся генерации
4. Скачает и сохранит
5. Перейдёт к следующему

### Автопереименование скачанного

Скачанные файлы обычно называются случайными строками — попросите AI переименовать:

```
Переименуй только что скачанную картинку в cyberpunk-street.png
```

```bash
mv ~/Downloads/jimeng-2026-03-15-xxx.png ~/Desktop/images/cyberpunk-street.png
```

## Типичные проблемы

| Симптом | Причина | Решение |
|-----|-----|-----|
| Страница не открывается | Проблемы сети | Для Gemini нужен VPN; для Jimeng проверьте вход в аккаунт |
| Промпт заблокирован | Модерация контента | Описательные обходы, без брендов и стоп-слов |
| Не найти каталог загрузок | Разный язык системы | В Linux с китайским языком — `~/下载/`, с английским — `~/Downloads/` |
| Генерация картинки не удалась | Серверы заняты | Подождите и повторите |
| MCP не подключается | В Chrome не включена удалённая отладка | Проверьте `chrome://inspect/#remote-debugging` |
