# A3 Ведение Xiaohongshu

> 💡 **Коротко**: постройте с OpenCode конвейер пакетного производства для Xiaohongshu: 7 заметок за раз, умный подбор тем из банка, комплектный выпуск текста с картинками.

<summary>📝 Текстовая версия шпаргалки</summary>

1. Структура: банк тем/ (по типам), банк материалов/, заметки/ (по месяцам), банк заголовков обложек.md, персона.md.
2. Персона аккаунта фиксируется в AGENTS.md: позиционирование, тон, стоп-слова, стиль заголовков, структура текста, 300–500 слов.
3. Пример персоны: разбор составов косметики, 25 лет, офисный работник, тон подруги; стоп-слова — китайский сленг (вроде 绝绝子, yyds).
4. Банк тегов-тем: уход (горячий), жизнь (средний), стиль (низкий) — определяют охваты.
5. Массовая генерация: 7 заметок за раз (неделя контента): заголовок обложки (до 10 знаков), текст (300–400 знаков), теги (5–8).
6. Взрывные заголовки: вопрос, цифры, контраст, боль.
7. OpenCode против веб-AI: пакетно/точно/контролируемо против поштучно/общо/рандомно.
8. Ошибки: стиль плывёт — персона не зафиксирована; теги мимо — нет банка тем; заголовки слабы — 1 версия; контент однотипен.

</details>

---

## Почему OpenCode, а не веб-версия AI?

| Возможность | Веб-версия AI | OpenCode |
|-----|----------|----------|
| Пакетные заметки | ❌ По одной, с копипастом | ✅ 7 штук за раз, сразу в файлы |
| Ведение банка тем | ❌ Каждый раз искать темы вручную | ✅ Локальный банк тем, умный подбор |
| Консистентность образа | ❌ Каждый раз описываете заново | ✅ Образ зафиксирован в AGENTS.md навсегда |
| Комплект текст+картинки | ❌ Текст и заголовок пишутся раздельно | ✅ Текст+обложка+теги — одним комплектом |
| Переиспользование истории | ❌ | ✅ Ссылки @материалы на прошлый контент |

## Повторите за мной

### Шаг 1: создайте структуру проекта Xiaohongshu

**Зачем**
Держать весь контент централизованно — удобно для пакетных операций.

```bash
mkdir ~/my-xiaohongshu
cd ~/my-xiaohongshu
opencode
```

Попросите AI построить структуру каталогов:

```
Создай структуру каталогов для ведения контента Xiaohongshu:
- банк-тем/ (по типам: уход за кожей, образы, еда и т. д.)
- банк-материалов/ (описания картинок, информация о продуктах, отзывы)
- заметки/ (по месяцам)
- банк-заголовков-для-обложек.md (шаблоны виральных заголовков)
- образ.md (определение образа аккаунта)

Создай эти каталоги и пустые файлы
```

### Шаг 2: зафиксируйте образ аккаунта

**Зачем**
Единый стиль — подписчики вас узнают.

```
Создай AGENTS.md с образом моего аккаунта Xiaohongshu:

Позиционирование: разбор составов уходовой косметики
Образ: 25-летняя офисная сотрудница с жирной кожей, склонной к акне, 3 года изучает составы
Тон: как совет подруги, искренне и без пафоса
Частые эмодзи: ✨ 💕 🌟 😭 ❗
Запрещённые слова: вау-эффект, имба, топчик (звучит фальшиво)
Стиль заголовков: вопросительные/цифровые/контрастные
Структура текста: боль → рекомендация продукта → впечатления → итог с советом
Объём: 300–2000+ знаков
```

### Шаг 3: создайте банк тем
<AdInArticle />

**Зачем**
Теги решают охваты — заготовьте их заранее, чтобы не искать каждый раз.

```
Создай банк тем по типам, каждый тип — отдельный файл:

банк-тем/уход-за-кожей.md:
#уходзакожей #рекомендации #составы #жирнаякожа #бюджетныйуход
#антивозрастнойуход #отбеливание #увлажнение #чувствительнаякожа #студенческийуход
(каждую тему пометь популярностью: высокая/средняя/низкая)

банк-тем/образы.md:
#образы #повседневныйобраз #офисныйобраз #стройнящийобраз #бюджетныйобраз
(и так далее)
```

### Шаг 4: пакетно создайте заметки на неделю

**Зачем**
7 заметок за раз — и неделя контента закрыта.

```
Создай 7 заметок Xiaohongshu на следующую неделю, тема — «уход за жирной кожей, склонной к акне».

Каждая заметка включает:
1. Заголовок для обложки (до 10 знаков, цепляющий)
2. Текст (300–400 знаков)
3. Теги (5–8 штук, выбрать из @банк-тем/уход-за-кожей.md)
4. Совет по картинке (описать, что снять)

Распределение тем на 7 дней:
- Понедельник: рекомендации очищения
- Вторник: сочетания тоника и крема
- Среда: обзор сывороток
- Четверг: сравнение SPF
- Пятница: опыт борьбы с акне
- Суббота: ошибки в уходе
- Воскресенье: пустые баночки

Сохрани в каталог заметки/2-я-неделя-января-2025/, каждая заметка — отдельный файл
```

### Шаг 5: соберите банк виральных заголовков

**Зачем**
Хороший заголовок = высокая кликабельность, их стоит коллекционировать.

```
Собери «банк-заголовков-для-обложек.md» — шаблоны виральных заголовков Xiaohongshu:

【Вопросительные】
- У жирной кожи с акне правда есть спасение? Я нашла ответ
- Почему твоя уходовая косметика вечно не работает?

【Цифровые】
- 3 сыворотки, которые я покупала 10 раз
- 30 дней подряд — и кожа реально изменилась

【Контрастные】
- Все в сети хвалят XX, месяц использования — рассказываю правду
- Хотела поругать, а влюбилась

【Болевые】
- Лицо после бессонных ночей спасено! Этот способ — огонь
- Чёрные точки и «клубничный нос»? Вот как решила я

Каждого типа по 10 шаблонов, сохрани в банк-заголовков-для-обложек.md
```

## 📋 Волшебный промпт

### 📝 Пакетная генерация заметок
> Ожидаемый эффект: несколько заметок Xiaohongshu за раз — с текстом, заголовками и тегами

```
## Роль
Ты — опытный блогер Xiaohongshu: мастер виральных заметок. Знаешь тон платформы и психологию пользователей.

## Задача
Пакетно создать заметки Xiaohongshu: каждая с заголовком для обложки, текстом, тегами и советом по картинке.

## Входные данные
### Обязательные
- Позиционирование аккаунта: 【позиционирование】
- Тема пачки: 【направление темы】
- Сколько создать: 【N】 штук

### Необязательные
- Образ для сверки: @AGENTS.md
- Банк тем: @банк-тем/【тип】.md

## Формат вывода
Каждая заметка включает:

### Заметка 1: 【тема】
**Заголовок для обложки** (до 10 знаков, цепляющий)
> 【заголовок】

**Текст** (300–400 знаков)
> 【текст в стиле Xiaohongshu】

**Теги** (5–8 штук)
> #тег1 #тег2 ...

**Совет по картинке**
> 【описать, что снять】

---

## Ограничения
- ✅ Заголовок с ударом, до 10 знаков
- ✅ Текст разговорный, как совет подруги
- ✅ Теги из популярных тем
- ✅ Уместные эмодзи
- ❌ Без заезженных «вау», «имба» и подобного мусора
- ❌ Без преувеличений, держи искренность
```

### 🏷️ Обновление банка тем
> Ожидаемый эффект: живой банк тегов, выше охваты заметок

````
## Роль
Ты — эксперт по ведению Xiaohongshu: исследователь тем и оптимизатор тегов.

## Задача
Обновить банк тегов: разобрать популярность, оптимизировать стратегию тегов.

## Входные данные
### Обязательные
- Тип тем: 【тип, например уход/образы/еда】
- Текущий банк тем: @банк-тем/【тип】.md

### Необязательные
- Новые темы: 【какие темы добавить?】

## Формат вывода
Обновлённый банк тем в формате:

```markdown
# Банк тем «【тип】»

## Высокая популярность (использовать в первую очередь)
- #тема1 — пояснение
- #тема2 — пояснение

## Средняя популярность (для сочетаний)
- #тема3 — пояснение

## Низкая популярность (точечный охват)
- #тема4 — пояснение

## Устаревшие (не использовать)
- #старая-тема — почему устарела

---
Обновлено: 【дата】
```

## Ограничения
- ✅ Деление по популярности для удобного выбора
- ✅ У каждой темы пометка о применении
- ✅ Устаревшие темы помечены, чтобы не использовать по ошибке
- ❌ Не добавлять темы вне позиционирования
````

### ✨ Оптимизация заголовков для обложек
> Ожидаемый эффект: несколько запасных заголовков, выше кликабельность

```
## Роль

## Задача

## Входные данные

### Необязательные

- Стиль-табу: 【какой стиль не нужен?】

## Формат вывода
Создай 10 заголовков разных стилей:

### Вопросительные (2–3 штуки)
> Интригуют, провоцируют клик
- 【заголовок】 ⭐⭐⭐⭐⭐
- 【заголовок】 ⭐⭐⭐⭐

### Цифровые (2–3 штуки)

## Ограничения
```

## Типичные проблемы

| Симптом | Причина | Решение |
|-----|-----|-----|
| Стиль заметок каждый раз разный | Образ не зафиксирован | Запишите образ в AGENTS.md |
| Теги неточные | Нет банка тем | Создайте банк тем по типам |
| Заголовки для обложек не цепляют | Написан один вариант | Генерируйте по 10 запасных |
| Контент однообразный | Каждый раз один и тот же промпт | Меняйте темы и ракурсы |

```markdown

---

Требования:
```
