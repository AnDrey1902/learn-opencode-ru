# 2.1b Как копировать содержимое

> 💡 **Первый вопрос новичка**: «Почему после Ctrl+C программа сразу закрывается?!»

## 📝 Конспект урока

<details>
<summary>📝 Текстовая версия шпаргалки</summary>

**Ctrl+C в терминале — не копирование**: это принудительная остановка программы; в OpenCode — очистка ввода или выход.

**3 способа копировать**: выделить мышью и отпустить (автокопирование); Ctrl+X → Y (Y = Yank, мнемоника из Vim); команда `/copy` (копирует весь диалог).

- Windows: Shift + выделение → Enter или правая кнопка для подтверждения.
- Баг «кракозябр» в Windows: грубый выход через Ctrl+C портит символы — выходите элегантно через **Ctrl+D**.

## 💥 Почему Ctrl+C не работает?

Для тех, кто привык к Word и браузеру, это может стать настоящим культурным шоком.

В мире терминала (того самого чёрного окна, где работает OpenCode) `Ctrl+C` обычно служит сигналом прерывания, а не сочетанием для копирования.

- **В Word**: `Ctrl+C` = 📷 **снимок** (копирование содержимого)
- **В терминале**: `Ctrl+C` = 🛑 **прерывание**

Поэтому в OpenCode нажатие `Ctrl+C` не копирует выделенное содержимое.

---

## 🚀 Способ 1: мышь (самый понятный)

Это «скрытая возможность», специально предусмотренная OpenCode для современных пользователей; она работает и в **Windows, и в macOS**.

### Порядок действий

1. **Нажмите левую кнопку мыши** и протяните курсор, выделив нужный текст.
2. **Отпустите левую кнопку мыши**.
3. **Готово!** 🎉

Да, вы всё правильно поняли. Не нужно нажимать правую кнопку или какую-либо клавишу. В момент, когда вы **отпускаете мышь**, OpenCode автоматически копирует выделенное в буфер обмена и показывает сообщение `Copied to clipboard`.

---

## ⌨️ Способ 2: клавиатура (самый быстрый)

Если вам нужна только **последняя реплика AI** (например, большой фрагмент кода), выделять её мышью слишком утомительно.

### Порядок действий

1. Нажмите клавишу **Leader** (по умолчанию <kbd>Ctrl</kbd>+<kbd>X</kbd>).
2. Отпустите все клавиши.
3. Нажмите <kbd>Y</kbd>.

**Как запомнить**: `Y` = **Y**ank (жаргон программистов для «копировать»).

> Хотите узнать больше сочетаний клавиш? Смотрите **[2.3 Рекомендуемые сочетания клавиш](./03-shortcuts)**.

---

## 📜 Способ 3: команда (самый полный)

Если нужно сохранить **всю историю диалога** (ваши сообщения и ответы AI), отправить её другу или добавить в документ.

### Порядок действий

1. Введите `/copy` в поле ввода.
2. Нажмите <kbd>Enter</kbd>.

Вся история диалога будет полностью скопирована.

---

## 🛡️ Запасной вариант: системное копирование

Если «секретные приёмы» выше не работают или вы хотите использовать штатный способ системы.

| Система | Действие |
|------|------|
| **macOS** | Удерживайте <kbd>Option (⌥)</kbd> и выделите мышью → <kbd>Command</kbd>+<kbd>C</kbd> |
| **Windows** (до v1.1.64) | Удерживайте <kbd>Shift</kbd> и выделите мышью → <kbd>правая кнопка</kbd> или <kbd>Enter</kbd> |
| **Windows** (v1.1.64+) | Выделите мышью → автоматическое копирование или <kbd>Ctrl</kbd>+<kbd>C</kbd> |

**Когда это использовать**:
- OpenCode завис и не реагирует
- нужно точно скопировать сообщение об ошибке
- окно терминала перехватывается другой программой

## Повторите за мной

### Шаг 1: проверьте Ctrl+C
1. Введите несколько символов в поле ввода (не отправляйте их).
2. Нажмите <kbd>Ctrl</kbd>+<kbd>C</kbd>.
3. Видите, что поле очистилось? Ctrl+C распознался как сигнал прерывания.

### Шаг 2: проверьте «автоматическое копирование»
1. Попросите AI сказать что-нибудь (например, отправьте `hi`).
2. Выделите мышью несколько слов в ответе AI.
3. **Отпустите мышь**.
4. Откройте любой текстовый редактор и вставьте текст через `Ctrl+V`.
5. Получилось?

### Шаг 3: проверьте «принудительное копирование»
1. Вернитесь в OpenCode.
2. **Пользователи macOS**: удерживайте <kbd>Option</kbd>; **пользователи Windows**: удерживайте <kbd>Shift</kbd>.
3. Выделите мышью фрагмент текста.
4. Этот способ обходит OpenCode и напрямую использует функцию выделения терминала.

## 🚑 Устранение неполадок: что делать, если на экране появились нечитаемые символы?

**Симптом**: пользователи Windows после выхода через `Ctrl+C` могут заметить, что при движении мыши на экране появляется набор символов вроде `[555;38;16M`.

**Причина**:
- При запуске OpenCode включается «режим отслеживания мыши».
- В Windows `Ctrl+C` — это сигнал принудительного выхода (SIGINT).
- OpenCode не успевает сообщить терминалу «отключить отслеживание мыши», и процесс завершается.
- Терминал считает, что программа всё ещё работает, и продолжает отправлять координаты мыши на экран, превращая их в нечитаемые символы.

> 🐛 **Известная проблема**: в OpenCode вплоть до версии **v1.1.25** эта проблема в Windows не была полностью исправлена. Это ограничение низкоуровневой реализации; рекомендуется пользоваться таблицей ниже.

**Решение**:
1. **Экстренная мера**: закройте текущее окно терминала и откройте его заново.
2. **Профилактика (настоятельно рекомендуется)**: не выходите из программы через `Ctrl+C`! Используйте **Ctrl+D**.

| Способ выхода | Характер | Результат |
|---------|------|------|
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | 🔪 **Жёсткое завершение** (Force Kill) | Может привести к нечитаемым символам мыши, не рекомендуется |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> | 👋 **Выход** (Soft Exit) | Корректный выход с автоматической очисткой, **рекомендуется** |

> **Подсказка**: `Ctrl+D` запускает логику очистки OpenCode и гарантирует корректное отключение режима мыши.

## 🎉 Хорошая новость: работа в Windows значительно улучшена (v1.1.64+)

> 🪟 **Только для Windows**: если вы используете **OpenCode v1.1.64 или новее**, поздравляем!

Начиная с v1.1.64 выбор текста в Windows стал значительно удобнее:

| Улучшение | Раньше | Теперь |
|--------|------|------|
| Выделение мышью | Нужно было удерживать Shift | Достаточно протянуть мышь |
| Копирование через Ctrl+C | Не поддерживалось | Поддерживается для ручного копирования выделенного |

**Теперь пользователи Windows могут**:
- выделять текст мышью, как в обычном текстовом редакторе
- после выделения вручную копировать его через `Ctrl+C` (если автоматическое копирование не сработало)

> 📌 **Проверка версии**: введите `/version`, чтобы узнать версию OpenCode.

Логика OpenCode «копировать при отпускании мыши» не является поведением терминала по умолчанию — это продвинутая функция, реализованная в коде:

| Функция | Путь к файлу | Ключевая логика |
|-----|---------|----------|
| Логика копирования мышью | [`src/cli/cmd/tui/app.tsx`](https://github.com/anomalyco/opencode/blob/dev/packages/opencode/src/cli/cmd/tui/app.tsx) | обработчик события `onMouseUp` |
| Инструмент буфера обмена | [`src/cli/cmd/tui/util/clipboard.ts`](https://github.com/anomalyco/opencode/blob/dev/packages/opencode/src/cli/cmd/tui/util/clipboard.ts) | кроссплатформенная поддержка буфера обмена |
| Улучшение выбора в Windows (v1.1.64) | ключевые слова поиска `windows`, `win32`, `selection` | `packages/opencode/src/` |

**Команда для поиска в исходном коде**:
```bash
grep -rn "windows\|win32\|selection" packages/opencode/src/
```

**Ключевой фрагмент кода (`app.tsx`):**
```typescript
// Когда кнопку мыши отпустили
onMouseUp={async () => {
  // 1. Забираем выделенный текст
  const text = renderer.getSelection()?.getSelectedText()
  if (text && text.length > 0) {
    // 2. Копируем через Clipboard API
    await Clipboard.copy(text)
    // 3. Показываем подсказку
    toast.show({ message: "Copied to clipboard" })
    // 4. Снимаем выделение
    renderer.clearSelection()
  }
}}
```
