### Обзор интерфейса TUI

После запуска OpenCode вы увидите примерно такой интерфейс:

```
┌─────────────────────────────────────────────────┐
│  OpenCode v1.0.0                    режим Build │  ← статус-бар/шапка
├─────────────────────────────────────────────────┤
│                                                 │
│  AI: Привет! Чем помочь?                        │  ← зона диалога
│                                                 │
├─────────────────────────────────────────────────┤
│  > Спроси что-нибудь...                         │  ← поле ввода
└─────────────────────────────────────────────────┘
```

| Область | Назначение |
|-----|------|
| Строка состояния/заголовок | Версия, текущий режим (Plan/Build), расход токенов |
| Боковая панель | Список сессий (на широком экране показывается автоматически, на узком скрыт) |
| Область диалога | Ответы AI и история ваших сообщений |
| Область ввода | Место для ввода сообщений (подсказка зависит от режима) |

::: details Правила отображения интерфейса

**1. Автоматическое отображение боковой панели**
- На широком экране (>120 столбцов) список сессий показывается автоматически
- На узком экране он скрывается, чтобы сэкономить место

**2. Умные подсказки в поле ввода**
- В разных режимах отображаются разные подсказки-заполнители
- Обычный режим: `Что-нибудь спросите...`
- Режим Shell: `Введите команду shell...`
- Режим сводки комментариев: `Составьте сводку комментариев...`
:::

### Три основные операции

| Символ | Назначение | Пример |
|-----|------|------|
| `@` | Ссылка на файл | `@src/main.ts что делает этот файл` |
| `!` | Выполнение команды | `!ls -la` — просмотр каталога |
| `/` | Slash-команда | `/help` — справка |

## Повторите за мной

### Шаг 1: запустите OpenCode в проекте

**Зачем**  
Запускайте OpenCode из каталога проекта, чтобы AI видел файлы с кодом.

```bash
cd ~/your-project  # подставь путь к своему проекту
opencode
```

### Шаг 2: попросите AI представиться

**Зачем**  
Проверим, что базовый диалог работает.

Введите в области ввода:

```
Привет! Коротко расскажи о себе
```

Нажмите <kbd>Enter</kbd>, чтобы отправить сообщение.

**Вы должны увидеть**: AI ответит коротким представлением.

### Шаг 3: сошлитесь на файл через @

**Зачем**  
Это одна из самых мощных функций OpenCode: AI сможет напрямую прочитать ваш файл.

Введите:

```
@package.json что за проект описан в этом файле
```

::: tip 💡 Поиск и автодополнение
После ввода `@` появятся список Agent (например, `@explore`) и каталоги. **Продолжайте вводить часть имени файла** (например, `@pack`), чтобы найти подходящие файлы; выберите нужный стрелками и нажмите <kbd>Enter</kbd>.
:::

**Вы должны увидеть**: AI проанализирует содержимое package.json и ответит.

### Шаг 4: выполните команду через !

**Зачем**  
Так AI увидит результат выполнения команды.

Введите:

```
!ls -la
```

**Вы должны увидеть**: список файлов текущего каталога появится в диалоге.

Можно также попросить AI выполнить команду:

```
Покажи, какие файлы в текущей папке
```

AI автоматически вызовет подходящий инструмент.

### Шаг 5: вызовите slash-команду через /

**Зачем**  
Slash-команды — это встроенный в OpenCode способ доступа к функциям.

Введите:

```
/help
```

**Вы должны увидеть**: список всех доступных slash-команд.

Краткий список полезных slash-команд:

| Команда | Назначение |
|-----|------|
| `/help` | Открыть справку |
| `/new` | Создать сессию |
| `/models` | Переключить модель |
| `/themes` | Сменить тему |
| `/exit` | Выйти |

::: tip 💡 Палитра команд
Нажмите <kbd>Ctrl</kbd>+<kbd>P</kbd>, чтобы открыть палитру команд; <kbd>Ctrl</kbd>+<kbd>X</kbd> — это префикс Leader, он сам по себе палитру не открывает.
:::

### Шаг 6: изучите полезные сочетания клавиш

**Зачем**  
Сочетания клавиш ускоряют работу.

| Сочетание | Назначение |
|-------|------|
| <kbd>Tab</kbd> | Переключить режим Plan/Build |
| <kbd>Esc</kbd> | Прервать текущий ответ или вернуться на уровень выше |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Очистить ввод; также используется для выхода из приложения |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> | Клавиша Leader (клавиша-префикс) |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> <kbd>N</kbd> | Создать сессию |

### Шаг 7: проверьте изменения в diff viewer

Введите `/diff` (или найдите `Open diff viewer` в палитре команд), чтобы открыть включённый по умолчанию diff viewer. Он организует изменения в виде дерева файлов и поддерживает:

- навигацию по файлам и hunk
- переключение между отдельным patch и всеми patch
- переключение между единой и двухпанельной видами (в слишком узком терминале доступен только единый вид)
- просмотр изменений рабочего каталога и изменений, созданных AI в последнем цикле; если текущая ветка не является веткой по умолчанию, также просмотр различий с основной веткой

Полезные клавиши: <kbd>]</kbd> / <kbd>[</kbd> переключают hunk, <kbd>n</kbd> / <kbd>p</kbd> — файл, <kbd>d</kbd> — источник, <kbd>v</kbd> — представление, <kbd>m</kbd> отмечает файл как просмотренный, <kbd>?</kbd> открывает полную справку, <kbd>Esc</kbd> / <kbd>q</kbd> закрывают viewer и возвращают на предыдущий экран.

> Исходный код: [навигация и источники diff viewer в v1.18.22](https://github.com/anomalyco/opencode/blob/v1.18.22/packages/tui/src/feature-plugins/system/diff-viewer.tsx#L563-L704), [команда входа](https://github.com/anomalyco/opencode/blob/v1.18.22/packages/tui/src/feature-plugins/system/diff-viewer.tsx#L1045-L1071).

::: details 📦 Что такое клавиша Leader
Leader — это способ составлять сочетания клавиш. Сначала нажмите <kbd>Ctrl</kbd>+<kbd>X</kbd>, отпустите, а затем нажмите другую клавишу.

Например: <kbd>Ctrl</kbd>+<kbd>X</kbd>, затем <kbd>N</kbd> = новая сессия.

Так можно поддерживать больше сочетаний, не конфликтуя с системными клавишами.
:::

## Типичные проблемы

| Симптом | Причина | Решение |
|-----|-----|-----|
| После `@` нет автодополнения файлов | OpenCode запущен не из каталога проекта | Выполните `cd` в каталог проекта и перезапустите |
| Команда `!` сообщает об ошибке доступа | OpenCode перехватил опасную команду | Убедитесь, что команда безопасна, и нажмите `y` для разрешения |
| Сочетание клавиш не работает | Терминал перехватывает клавишу | Проверьте настройки терминала или смените терминал |
