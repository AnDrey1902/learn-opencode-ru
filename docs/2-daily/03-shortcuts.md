## Основная идея

### Механизм клавиши Leader (важно!)

OpenCode использует **клавишу Leader** (по умолчанию <kbd>Ctrl</kbd>+<kbd>X</kbd>) как префикс сочетаний, чтобы избежать конфликтов с клавишами терминала.

::: info 🤔 Что такое клавиша Leader?
Leader похожа на `<Leader>` в Vim или на «комбинацию клавиш» в играх. Это не функциональная клавиша, а **клавиша-префикс**.

После нажатия Leader OpenCode ждёт, пока вы нажмёте букву: только вместе они образуют полное сочетание клавиш.
:::

**Порядок действий (три шага)**:

```
┌─────────────────────────────────────────────────────────────┐
│  第 1 步          第 2 步          第 3 步                   │
│  按下 Ctrl+X  →   松开所有键   →   按下字母键（如 N）        │
│                                                             │
│  ⚠️ 关键：第 2 步必须松开！不是同时按住三个键！              │
└─────────────────────────────────────────────────────────────┘
```

**Примеры**:

| Что нужно сделать | Правильная последовательность | Ошибочная последовательность |
|-----------|---------|---------|
| Создать сессию | Нажать Ctrl+X → отпустить → нажать N | ❌ Одновременно нажать Ctrl+X+N |
| Открыть список сессий | Нажать Ctrl+X → отпустить → нажать L | ❌ Удерживать Ctrl, нажать X, затем L |
| Переключить модель | Нажать Ctrl+X → отпустить → нажать M | ❌ Нажать слишком быстро, не отпустив клавиши |

::: tip 💡 Совет для тренировки
Поначалу можно **намеренно выполнять последовательность медленно**: после Ctrl+X мысленно сосчитайте до «1», затем нажмите букву. С опытом скорость придёт сама.
:::

### Критерии отбора

Из более чем 60 сочетаний мы выбрали клавиши по следующим критериям:

1. **Частое использование** — пригодятся почти каждый день
2. **Экономия времени** — гораздо быстрее ввода команд
3. **Простота запоминания** — подчиняются понятным закономерностям

### 🔥 Первый уровень: каждый день

Эти 8 сочетаний используются чаще всего — запомните их в первую очередь:

| Сочетание | Функция | Описание |
|--------|------|------|
| <kbd>Enter</kbd> | Отправить сообщение | Отправка по Enter |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | **Перенос строки (без отправки)** | Для многострочных промптов |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Очистить ввод / закрыть диалог / выйти | Подробнее ниже |
| <kbd>Escape</kbd> | Прервать ответ AI | Нажмите во время генерации, чтобы остановить её. **Два нажатия — принудительная остановка** |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Просмотреть историю ввода | **Когда поле ввода пусто**, стрелки возвращают ранее отправленные сообщения |
| <kbd>Tab</kbd> | Переключить Agent | Переключение между Plan/Build и разными Agent |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> → <kbd>N</kbd> | Создать сессию | Leader + N = **N**ew |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> → <kbd>L</kbd> | Список сессий | Leader + L = **L**ist |

::: tip 💡 Несколько способов перенести строку
Помимо <kbd>Shift</kbd>+<kbd>Enter</kbd>, можно использовать:
- <kbd>Ctrl</kbd>+<kbd>Enter</kbd>
- <kbd>Alt</kbd>+<kbd>Enter</kbd>
- <kbd>Ctrl</kbd>+<kbd>J</kbd>

Достаточно выбрать и запомнить удобный для вас вариант.
:::

::: details 📦 Три действия Ctrl+C (обновление v1.1.58)
- **Когда открыт диалог**: закрывает диалог (например, окно подтверждения или выбора)
- **Когда в поле есть текст**: очищает поле (не выходит)
- **Когда поле пусто**: выходит из OpenCode

⚠️ Внимание: хотя и Ctrl+C, и Ctrl+D позволяют выйти, их поведение немного различается. Ctrl+D сразу подаёт сигнал выхода, а Ctrl+C сначала пытается очистить ввод. Это соответствует поведению терминала и знакомо программистам.
:::

### 🧑‍💻 Для программистов: сочетания в поле ввода

Если вы пользовались терминалом или Emacs, эти сочетания будут вам знакомы:

| Сочетание | Функция | Стиль Readline |
|--------|------|--------------|
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Перейти в начало строки | ✅ |
| <kbd>Ctrl</kbd>+<kbd>E</kbd> | Перейти в конец строки | ✅ |
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | Удалить от курсора до конца строки | ✅ |
| <kbd>Ctrl</kbd>+<kbd>U</kbd> | Удалить от курсора до начала строки | ✅ |
| <kbd>Ctrl</kbd>+<kbd>W</kbd> | Удалить предыдущее слово | ✅ |
| <kbd>Alt</kbd>+<kbd>B</kbd> | Перейти на слово назад | ✅ |
| <kbd>Alt</kbd>+<kbd>F</kbd> | Перейти на слово вперёд | ✅ |

::: details 📦 Что такое стиль Readline?
Readline — стандартная библиотека ввода терминала Unix/Linux, определяющая набор общих сочетаний клавиш.

Почти все терминальные программы (bash, zsh, Python REPL) поддерживают эти сочетания. Если вы каждый день работаете в терминале, они уже стали мышечной памятью.

OpenCode полностью совместим с Readline, поэтому в поле ввода можно редактировать текст привычным способом.
:::

## Повторите за мной

### Шаг 1: потренируйтесь переносить строки

**Зачем**  
При написании многострочного промпта нужно переносить строку, а не отправлять сообщение.

1. Введите `первая строка` в поле ввода.
2. Нажмите <kbd>Shift</kbd>+<kbd>Enter</kbd>.
3. Введите `вторая строка`.

**Вы должны увидеть**: в поле ввода две строки, а сообщение не отправлено.

::: warning ⚠️ Частая проблема
Если <kbd>Shift</kbd>+<kbd>Enter</kbd> не переносит строку, а сразу отправляет сообщение, терминал не поддерживает клавиши-модификаторы. Решение:
- используйте <kbd>Ctrl</kbd>+<kbd>J</kbd> (поддерживается шире);
- или настройте терминал по инструкции [5.6b Сочетания клавиш](../5-advanced/06b-keybinds#终端兼容性).
:::

### Шаг 2: потренируйтесь работать с историей

**Зачем**  
Чтобы повторно отправить или изменить предыдущее сообщение, не нужно вводить его заново.

1. Сначала отправьте сообщение: `привет`.
2. Дождитесь ответа AI и убедитесь, что поле ввода пусто.
3. Нажмите <kbd>↑</kbd> (стрелка вверх).

**Вы должны увидеть**: поле ввода автоматически заполнилось отправленным сообщением `привет`.

Продолжайте нажимать <kbd>↑</kbd>, чтобы просматривать более ранние сообщения, а <kbd>↓</kbd> — чтобы вернуться к более поздним.

### Шаг 3: потренируйтесь с Ctrl+C

**Зачем**  
Это позволяет быстро очистить ввод, закрыть диалог или выйти из OpenCode.

**Сценарий A — очистить ввод**:
1. Введите текст в поле ввода.
2. Нажмите <kbd>Ctrl</kbd>+<kbd>C</kbd>.

**Вы должны увидеть**: поле ввода очистилось.

**Сценарий B — закрыть диалог**:
1. Откройте диалог (например, нажмите <kbd>Ctrl</kbd>+<kbd>X</kbd> → <kbd>L</kbd>, чтобы открыть список сессий).
2. Нажмите <kbd>Ctrl</kbd>+<kbd>C</kbd>.

**Вы должны увидеть**: диалог закрылся, и вы вернулись к обычному интерфейсу.

**Сценарий C — выйти из приложения**:
1. Убедитесь, что поле ввода пусто и диалог не открыт.
2. Нажмите <kbd>Ctrl</kbd>+<kbd>C</kbd>.

**Вы должны увидеть**: OpenCode завершил работу.

### Шаг 4: потренируйтесь с сочетаниями Leader

**Зачем**  
Это основной механизм сочетаний клавиш OpenCode.

**Важно**: это последовательность из двух действий, а не одновременное нажатие!

1. Нажмите <kbd>Ctrl</kbd>+<kbd>X</kbd>.
2. **Отпустите все клавиши** (это очень важно!).
3. Нажмите <kbd>N</kbd>.

**Вы должны увидеть**: создана новая сессия.

Теперь попробуйте открыть список сессий:

1. Нажмите <kbd>Ctrl</kbd>+<kbd>X</kbd>.
2. **Отпустите клавиши**.
3. Нажмите <kbd>L</kbd>.

**Вы должны увидеть**: появился список сессий.

### Шаг 5: потренируйтесь отменять и повторять действия

**Зачем**  
Если ответ AI вас не устраивает, его можно отменить и начать заново.

1. Отправьте сообщение AI.
2. Дождитесь ответа AI и нажмите <kbd>Ctrl</kbd>+<kbd>X</kbd> → <kbd>U</kbd>.

**Вы должны увидеть**: последнее сообщение и ответ отменены.

Нажмите <kbd>Ctrl</kbd>+<kbd>X</kbd> → <kbd>R</kbd>, чтобы повторить действие.

### Шаг 6: потренируйтесь прерывать ответ

**Зачем**  
Это помогает вовремя остановить слишком длинный или ошибочно направленный ответ AI.

1. Отправьте сложный вопрос.
2. Во время ответа AI нажмите <kbd>Escape</kbd>.

**Вы должны увидеть**: AI прекратил генерацию.

## Типичные проблемы

| Симптом | Причина | Решение |
|-----|-----|-----|
| Shift+Enter не переносит строку, а отправляет сообщение | Терминал не передаёт клавишу-модификатор | Используйте <kbd>Ctrl</kbd>+<kbd>J</kbd> или настройте терминал |
| После Ctrl+X и N ничего не происходит | Ctrl+X не был отпущен перед N | **Сначала обязательно отпустите клавиши**, затем нажмите N |
| Ctrl+X не работает | Терминал перехватывает сочетание | Проверьте настройки или смените терминал |
| **Ctrl+C не копирует** | Очищает ввод или выполняет выход, а не копирование | Для копирования используйте <kbd>Ctrl</kbd>+<kbd>X</kbd> → <kbd>Y</kbd> или выделите мышью и нажмите <kbd>Ctrl</kbd>+<kbd>V</kbd>
| Стрелка вверх не показывает историю | Поле ввода не пусто | Сначала очистите поле (Ctrl+C), затем нажмите стрелку вверх |
| Tab не переключает Agent | Клавиша нажата в режиме ввода | Нажмите Escape, чтобы выйти из ввода, затем Tab |
| **Ctrl+Z неожиданно приостановил работу** | Вы приняли его за отмену, но он приостанавливает терминал | OpenCode приостановится; введите в терминале `fg`, чтобы продолжить. Не используйте это для «отмены»! |
