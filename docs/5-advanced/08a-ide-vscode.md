## Способы установки

### Автоматическая установка (рекомендуется)

1. Откройте VS Code
2. Откройте **встроенный терминал** (не внешний)
3. Выполните `opencode` — расширение установится само

### Ручная установка

1. Откройте маркет расширений (`Cmd+Shift+X` / `Ctrl+Shift+X`)
2. Найдите "OpenCode"
3. Нажмите «Установить»

## Процесс работы

1. `Cmd+Esc` — открыть панель OpenCode
2. Выделите код в редакторе
3. `Cmd+Option+K` — вставить ссылку на файл
4. Введите вопрос и отправьте Enter

### Автоопределение выделенных строк

Расширение само определяет выделенное в редакторе и создаёт ссылку с номерами строк:

| Что выделено | Созданная ссылка | Пояснение |
|---------|-----------|------|
| Строка 10 | `@file.ts#L10` | Одна строка |
| Строки 10–20 | `@file.ts#L10-20` | Диапазон строк |
| Ничего не выделено | `@file.ts` | Весь файл |

**Пример использования**:

1. Выделите в редакторе строки 15–25 кода
2. Нажмите `Cmd+Option+K`
3. В поле ввода OpenCode само подставится `@src/utils.ts#L15-25`
4. Введите «оптимизируй этот код» — AI посмотрит только эти 10 строк

::: tip 💡 Почему ссылки со строками, а не вставка кода?
Ссылки со строками заставляют AI читать файл, и тогда:
- AI видит полный контекст файла (соседние функции, определения типов и т. д.)
- После правок кода ссылки всегда указывают на верное место
- Диалог не раздувается, экономятся токены
:::

## Настройка внешнего редактора

Когда в TUI используете команды `/editor` или `/export`, OpenCode открывает внешний редактор.

### Linux / macOS

```bash
# VS Code
export EDITOR="code --wait"

# Cursor
export EDITOR="cursor --wait"

# Vim
export EDITOR="vim"

# Nano
export EDITOR="nano"
```

Добавьте в конфиг shell (`~/.bashrc` или `~/.zshrc`), чтобы действовало всегда.

### Windows CMD

```cmd
set EDITOR=notepad

rem VS Code (нужен --wait)
set EDITOR=code --wait
```

Для постоянного действия задайте через **Свойства системы** > **Переменные среды**.

### Windows PowerShell

```powershell
$env:EDITOR = "notepad"

# VS Code (нужен --wait)
$env:EDITOR = "code --wait"
```

Для постоянного действия добавьте в профиль PowerShell.

### Частые редакторы

| Редактор | Команда | Нужен `--wait` |
|--------|------|---------------|
| VS Code | `code` | Да |
| Cursor | `cursor` | Да |
| Windsurf | `windsurf` | Да |
| Neovim | `nvim` | Нет |
| Vim | `vim` | Нет |
| Nano | `nano` | Нет |
| Sublime Text | `subl` | Да |
| Notepad | `notepad` | Нет |

> Флаг `--wait` заставляет процесс редактора ждать закрытия — обязательное условие работы команды `/editor`.

## Диагностика неполадок

### Расширение не установилось само

Проверьте условия:

1. Запускайте `opencode` во **встроенном терминале** VS Code (не во внешнем)
2. CLI редактора установлен:
   - VS Code: доступна команда `code`
   - Cursor: доступна команда `cursor`
   - Windsurf: доступна команда `windsurf`
   - VSCodium: доступна команда `codium`

Если CLI не установлен:
- `Cmd+Shift+P` (macOS) / `Ctrl+Shift+P` (Windows)
- Найдите "Shell Command: Install 'code' command in PATH"

3. У VS Code есть права на установку расширений

## Типичные проблемы

| Симптом | Причина | Решение |
|-----|-----|-----|
| Расширение не установилось само | Запуск не во встроенном терминале | Выполните `opencode` во встроенном терминале VS Code |
| Горячие клавиши не работают | Конфликт с другим расширением | Проверьте настройки клавиш, устраните конфликт |
| Редактор не открывается | Не задана переменная EDITOR | Задайте `export EDITOR="code --wait"` |
| Редактор открывается и сразу закрывается | Нет флага `--wait` | Добавьте параметр `--wait` |

// sdks/vscode/src/extension.ts:119-133
const selection = activeEditor.selection
if (!selection.isEmpty) {
  // Номера строк в VSCode начинаются с 0, переводим в 1-based
  const startLine = selection.start.line + 1
  const endLine = selection.end.line + 1

  if (startLine === endLine) {
    filepathWithAt += `#L${startLine}`      // Одна строка: @file.ts#L10
  } else {
    filepathWithAt += `#L${startLine}-${endLine}`  // Несколько: @file.ts#L10-20
  }
}
