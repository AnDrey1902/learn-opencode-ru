::: warning ⚠️ websearch нужно включать отдельно
`webfetch` (чтение страниц) доступен по умолчанию, настраивать ничего не надо.

А вот `websearch` (поиск по сети) требует одного из условий:
- Хостед-модели OpenCode Zen (включается сам)
- Переменная окружения `OPENCODE_ENABLE_EXA=true`
- Переменная окружения `OPENCODE_EXPERIMENTAL=true` (заодно включит несколько экспериментальных функций)

Не уверены, доступен ли вам websearch, — просто попробуйте в OpenCode. Недоступные AI инструменты не попадают в его список инструментов.
:::

## Основная идея

В OpenCode два сетевых инструмента с чётким разделением:

| Инструмент | Что делает | Аналогия |
|------|--------|------|
| `websearch` | Ищет в интернете, возвращает список результатов | Как поиск в Google |
| `webfetch` | Забирает содержимое указанного URL | Как открыть страницу в браузере |

Типичный процесс:

```
Вы: подскажи, что нового в React 19

Действия AI:
  1. websearch "React 19 new features"  → пачка результатов поиска
  2. webfetch URL одного из результатов  → чтение содержимого страницы
  3. Сводит ответ для вас
```

Вам не нужно вручную говорить AI, какой инструмент брать, — спрашивайте как обычно. AI сам решит: искать или читать.

## Повторите за мной

### Шаг 1: включите websearch (не для Zen-пользователей)

Пользователям Zen-моделей шаг пропустите — websearch уже включён автоматически.

Остальным нужна переменная окружения:

```bash
# macOS / Linux: добавьте в ~/.bashrc или ~/.zshrc
export OPENCODE_ENABLE_EXA=true

# Затем откройте терминал заново или выполните
source ~/.zshrc
```

```powershell
# Windows PowerShell
$env:OPENCODE_ENABLE_EXA = "true"
```

**Вы должны увидеть**: после перезапуска OpenCode AI умеет пользоваться инструментом websearch.

---

### Шаг 2: попробуйте веб-поиск

Откройте OpenCode и введите вопрос, требующий свежих данных:

```
Подскажи, что нового в последней версии Bun
```

**Вы должны увидеть**: AI вызовет инструмент `websearch` и выведет примерно такой процесс:

```
⠋ websearch("Bun latest version new features 2026")

Web search: Bun latest version new features 2026

1. Bun v1.x: What's New
   URL: https://bun.sh/blog/...
   ...

2. Bun Release Notes
   URL: https://github.com/oven-sh/bun/releases
   ...
```

Затем AI сведёт ответ по результатам поиска.

---

### Шаг 3: попробуйте чтение содержимого страниц

Если нужная страница уже известна — попросите AI прочитать:

```
Прочитай содержимое этой страницы: https://bun.sh/docs/installation
```

**Вы должны увидеть**: AI вызовет инструмент `webfetch`, заберёт содержимое страницы и изложит главное.

::: tip 💡 Приёмы webfetch
- «Прочитай этот GitHub README» — быстро понять проект
- «Переведи главное из этой англоязычной документации» — AI прочитает и сразу переведёт
- «Сравни содержимое этих двух страниц» — дайте два URL, AI прочитает оба и сравнит
:::

### Шаг 4: используйте в связке

Поиск и чтение стыкуются. Например:

```
Словил ошибку "TypeError: Cannot read properties of undefined",
поищи свежие решения, найди самую релевантную статью и изложи главное
```

**Вы должны увидеть**: AI сначала поищет, найдёт релевантную статью, затем прочитает её через webfetch и изложит суть.

## Шпаргалка параметров websearch

Параметры вручную передавать не нужно — AI выберет сам. Но понимание поможет точнее формулировать промпты.

| Параметр | Описание | По умолчанию |
|------|------|--------|
| `query` | Ключевые слова поиска | Обязательный |
| `numResults` | Сколько результатов вернуть | 8 |
| `type` | Глубина поиска | `auto` |
| `livecrawl` | Живое сканирование: `fallback` (сканировать, если кэша нет) / `preferred` (сканировать в первую очередь) | `fallback` |
| `contextMaxCharacters` | Максимум символов контекста | 10000 (по умолчанию Exa API) |

### Глубина поиска

| Тип | Описание | Подходит для |
|------|------|---------|
| `auto` | Сбалансированный режим (по умолчанию) | Большинство случаев |
| `fast` | Быстрый ответ | Простые вопросы, важна скорость |
| `deep` | Глубокий поиск | Сложные вопросы, важна полнота |

::: tip 💡 Как повлиять на глубину поиска?
Намекните в промпте, например:
- «Быстро глянь» — AI, возможно, выберет `fast`
- «Исследуй поглубже» — AI, возможно, выберет `deep`
:::

## Шпаргалка параметров webfetch

| Параметр | Описание | По умолчанию |
|------|------|--------|
| `url` | Адрес забираемой страницы | Обязательный |
| `format` | Формат вывода | `markdown` |
| `timeout` | Тайм-аут (секунды) | 30 (максимум 120) |

### Как выбрать формат вывода

| Формат | Описание | Подходит для |
|------|------|---------|
| `markdown` | Конвертация в Markdown (по умолчанию) | Документация, блоги, README |
| `text` | Чистый текст | Нужен только текст, без форматирования |
| `html` | Исходный HTML | Нужно разобрать структуру страницы |

Обычно хватает `markdown` по умолчанию. AI сам превратит HTML-страницу в чётко структурированный Markdown.

## Типичные проблемы

### 1. websearch недоступен

Если AI не пользуется websearch — возможно, он не включён.

| Ваша ситуация | Решение |
|---------|---------|
| Хостед-модель Zen | Должен быть доступен сам, проверьте соединение |
| Свой API-ключ | Задайте `OPENCODE_ENABLE_EXA=true` и перезапуститесь |
| Переменную задали, но не работает | Проверьте, что переменная применяется: `echo $OPENCODE_ENABLE_EXA` |

### 2. Неверный формат URL

❌ Без протокола
```
Прочитай example.com/page
```

✅ Полный URL
```
Прочитай https://example.com/page
```

webfetch требует URL строго с `http://` или `https://` в начале.

### 3. Слишком большая страница

У webfetch лимит размера 5MB. Слишком большая цель (например, гигантский PDF) упадёт с `Response too large`.

В таком случае попросите AI забрать более точную страницу, а не весь огромный файл.

### 4. Плохие результаты поиска

❌ Слишком туманно
```
Поищи про React
```

✅ Конкретнее
```
Поищи использование хука useOptimistic в React 19 с примерами
```

Чем конкретнее ключевые слова, тем лучше результаты.

### 5. Сайт блокирует

Некоторые сайты режут автоматические запросы (например, защита Cloudflare). Заметив блокировку Cloudflare, OpenCode автоматически повторит раз с честным User-Agent, но срабатывает не всегда.

При ошибке 403 попробуйте:
- Взять URL аналогичного сайта
- Попросить AI поискать то же содержимое из других источников

## Итоги урока

| Инструмент | Что делает | Доступен по умолчанию |
|------|--------|---------|
| `webfetch` | Забирает содержимое указанной страницы | ✅ Да |
| `websearch` | Ищет в интернете | ⚠️ Нужен Zen или переменная окружения |

Запомните ограничения:
- Тайм-аут websearch: 25 секунд
- Тайм-аут webfetch: 30 секунд (по умолчанию), максимум 120 секунд
- Лимит размера webfetch: 5MB

В повседневной работе параметры помнить не нужно — спрашивайте как обычно. AI сам решит: искать или читать, и сам выберет подходящие параметры.

```
  OR Flag.OPENCODE_ENABLE_EXA === true
```

- `OPENCODE_ENABLE_EXA=true`
- `OPENCODE_EXPERIMENTAL=true` (включает все экспериментальные функции)
