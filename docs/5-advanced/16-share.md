# Делиться сессиями

<summary>📝 Текстовая версия шпаргалки</summary>

1. Принцип: создаётся публичная URL, история синхронизируется на сервер; формат `opncd.ai/s/<share-id>`.
2. Три режима: manual (ручной, /share), auto (автоматически), disabled (отключено).
3. Команды: /share — поделиться; /unshare — отменить доступ.
4. Приватность: шарится полная история; не шарить чувствительный код/данные; конфиденциальные проекты → disabled.
5. Enterprise: полное отключение для compliance; ограничение на SSO; self-hosted.
6. Конфиг: `"share": "manual" | "auto" | "disabled"`.

Функция шаринга OpenCode позволяет создавать публичные ссылки на диалоги — удобно для командной работы и просьб о помощи.

> Диалогом по ссылке может публично воспользоваться любой, у кого есть ссылка.

## Как это работает

При шаринге диалога OpenCode:

1. Создаёт для сессии уникальный публичный URL
2. Синхронизирует историю диалога на сервер
3. Открывает доступ к диалогу по ссылке вида `opncd.ai/s/<share-id>`

## Режимы шаринга

OpenCode поддерживает три режима шаринга:

### Ручной режим (по умолчанию)

По умолчанию — ручной режим. Сессии сами не шарятся, но вы можете делиться вручную командой `/share`:

```
/share
```

Она создаст уникальный URL и скопирует его в буфер обмена.

Явная настройка ручного режима в конфиге:

```json
{
  "$schema": "https://opncd.ai/config.json",
  "share": "manual"
}
```

### Автошаринг

Включите автошаринг всех новых диалогов, задав `share` как `"auto"` в конфиге:

```json
{
  "$schema": "https://opncd.ai/config.json",
  "share": "auto"
}
```

С включённым автошарингом каждый новый диалог автоматически делится и получает ссылку.

### Отключение шаринга

Полностью отключите шаринг, задав `share` как `"disabled"`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "share": "disabled"
}
```

Чтобы принудительно применить настройку в команде, добавьте её в проектный `opencode.json` и закоммитьте в Git.

## Отмена шаринга

Чтобы закрыть доступ к диалогу и убрать его из публичного доступа:

```
/unshare
```

Ссылка удалится вместе с данными диалога.

## Замечания о приватности

При шаринге диалогов учитывайте:

### Хранение данных

Расшаренный диалог остаётся доступным, пока вы явно не отмените шаринг, включая:

- полную историю диалога
- все сообщения и ответы
- метаданные сессии

### Рекомендации

- Делитесь только диалогами без чувствительной информации
- Проверяйте содержимое диалога перед шарингом
- Отменяйте шаринг после завершения совместной работы
- Не делитесь диалогами с проприетарным кодом или конфиденциальными данными
- Для чувствительных проектов отключайте шаринг полностью

## Корпоративная версия

Для корпоративного деплоя функцию шаринга можно:

- **полностью отключить** ради безопасности и комплаенс
- **ограничить** только пользователями с SSO-аутентификацией
- **разместить** на собственной инфраструктуре
