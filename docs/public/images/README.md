# Каталог картинок

Здесь лежат картинки для уроков.

## Структура

```
public/images/
├── 1-start/        # Этап 1: быстрый старт
├── 2-daily/        # Этап 2: повседневное использование
├── 3-workflow/     # Этап 3: эффективный процесс
├── 4-scenarios/    # Этап 4: сценарные практикумы
├── 5-advanced/     # Этап 5: глубокая настройка
└── appendix/       # Шпаргалки
```

## Именование

- Формат: `точка-функции.png` или `точка-функции.gif`
- Примеры:
  - `install-success.png` — скриншот успешной установки
  - `writer-workflow-demo.gif` — демо авторского процесса

## Как ссылаться

В Markdown не пишите префикс `public`:

```markdown
![Успешная установка](/images/1-start/install-success.svg)
```

## Что добавить

В места с пометкой `<!-- 📹 Место для демо ... -->` нужно положить соответствующие картинки/GIF.
