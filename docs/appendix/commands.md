# Шпаргалка слэш-команд

> В поле ввода наберите `/` для меню команд или нажмите `Ctrl+P` для палитры команд

---

## 📝 Конспект урока

Ключевые идеи урока в сжатом виде:

<img src="/images/appendix/commands-notes.mini.jpeg"
     alt="Шпаргалка: слэш-команды"
     data-zoom-src="/images/appendix/commands-notes.jpeg" />

<details>
<summary>📝 Текстовая версия шпаргалки</summary>

1. Встроенные: `/new`, `/sessions`, `/models`, `/connect`, `/undo`, `/compact`, `/theme`, `/share`.
2. Ввод `/` → меню; Ctrl+P → палитра команд; сокращений нет (`/theme`, не `/themes`).
3. `/connect`: выбор провайдера → ввод API Key → автоконфиг (хранится в `~/.local/share/opencode/auth.json`).
4. `/editor`: внешний редактор через `export EDITOR="code --wait"` в `.bashrc`/`.zshrc`.
5. `/init`: генерация `.opencode/` с `rules.md` и `command/`.
6. Свои команды: проектные `.opencode/command/*.md` и глобальные `~/.config/opencode/command/*.md`; параметры `$ARGUMENTS`, `$1`/`$2`..., `` `!command` `` (shell), `@file`.
7. Сложные команды — JSON-способом в `config.json`.
8. Ловушки: имена в ед.ч.; `/connect` требует рестарта; свои команды — в `.opencode/command/`.

</details>

## Список встроенных команд

| Команда | Функция | Описание |
|------|------|------|
| `/new` | Новая сессия | Создать новый диалог |
| `/sessions` | Список сессий | Посмотреть исторические сессии |
| `/models` | Смена модели | Выбрать модель |
| `/connect` | Добавить провайдера | Настроить API-ключ |
| `/undo` | Отменить | Отменить правки файлов |
| `/redo` | Повторить | Повторить отменённые правки |
| `/share` | Поделиться | Создать ссылку шаринга |
| `/unshare` | Отменить шаринг | Отменить шаринг |
| `/compact` | Сжать | Сжать контекст |
| `/editor` | Редактор | Открыть внешний редактор |
| `/export` | Экспорт | Экспортировать сессию |
| `/theme` | Тема | Сменить тему |
| `/init` | Инициализация | Создать правила проекта |
| `/help` | Помощь | Показать помощь |

> Обратите внимание: у команд нет коротких алиасов. Например, `/themes` должно быть `/theme`.

## Подробно о командах

### /new — новая сессия

Создаёт новую сессию диалога, очищая текущий контекст.

```
/new
```

**Сценарии использования**:
- Начало новой задачи
- Текущий диалог слишком длинный, нужен рестарт
- Переход на несвязанную тему

---

### /sessions — управление сессиями

Открывает список сессий, переключается на исторические.

```
/sessions
```

**Функции**:
- Просмотр всех исторических сессий
- Быстрое переключение сессий
- Удаление ненужных сессий

---

### /models — смена модели

Переключает используемую AI-модель.

```
/models
```

**Функции**:
- Просмотр списка доступных моделей
- Смена главной модели

---

### /connect — добавить провайдера

<AdInArticle />

Интерактивная настройка нового провайдера моделей.

```
/connect
```

Credentials хранятся в `~/.local/share/opencode/auth.json`.

**Поддерживаемые провайдеры**:
- DeepSeek, Moonshot, MiniMax, Z.AI и др.
- Anthropic, OpenAI, Google и др.
- Ollama и другие локальные модели

Подробности — [список провайдеров моделей](./providers)

---

### /undo и /redo — отмена и повтор

Отмена и повтор правок файлов, сделанных AI.

```
/undo   # Отменить прошлую правку
/redo   # Повторить отменённую правку
```

**Принцип**:
- Работает на Git
- Каждое изменение файлов автоматически создаёт контрольную точку
- Отменять и повторять можно многократно

---

### /share и /unshare — шаринг сессий

Создаёт ссылку шаринга сессии или отменяет шаринг.

```
/share     # Создать ссылку шаринга
/unshare   # Отменить шаринг
```

**Обратите внимание**:
- По ссылке содержимое сессии видит кто угодно
- Чувствительные данные (API-ключи и т. д.) не шарятся
- После отмены шаринга ссылка сразу умирает

---

### /compact — сжатие контекста

При длинном диалоге сжимает историю сообщений ради экономии токенов.

```
/compact
```

**Сценарии использования**:
- Диалог упёрся в лимит контекста
- Хочется сэкономить на API
- AI начал «забывать» раннее содержимое

**Принцип**:
- AI суммирует историю диалога
- Главная информация сохраняется
- Избыточное удаляется

---

### /editor — внешний редактор

Открывает внешний редактор для длинного текста.

```
/editor
```

**Сценарии использования**:
- Ввод больших кусков кода или текста
- Нужны сложные функции редактирования

**Настройка**:
```bash
export EDITOR="code --wait"   # VS Code
export EDITOR=vim             # Vim
```

---

### /export — экспорт сессии

Экспортирует текущую сессию в JSON-файл.

```
/export
```

---

### /theme — смена темы

Переключает тему TUI-интерфейса.

```
/theme
```

**Встроенные темы**:
- `opencode` — по умолчанию
- `system` — адаптивная под терминал
- `tokyonight` — токийская ночь
- `catppuccin` — капучино
- `gruvbox` — Gruvbox
- `nord` — северная

> Обратите внимание: команда `/theme`, а не `/themes`.

---

### /init — инициализация проекта

Создаёт файл правил для текущего проекта.

```
/init
```

**Функции**:
- Разбирает структуру проекта
- Создаёт правила проекта
- Создаёт каталог .opencode/

Подробности — [Инициализация проекта](../3-workflow/03-init)

---

### /help — помощь

Показывает справочную информацию и доступные команды.

```
/help
```

## Свои команды

Создавайте собственные слэш-команды, подробности — [Быстрые команды](../5-advanced/04-commands).

### Где лежат файлы команд

```
Уровень проекта: .opencode/command/*.md
Глобальный уровень: ~/.config/opencode/command/*.md
```

### Пример: команда /review

```markdown title=".opencode/command/review.md"
---
description: Ревью кода
---

Проверьте следующий код:
$ARGUMENTS
```

Использование:

```
/review @src/main.ts
```

### Параметры команд

| Плейсхолдер | Описание |
|--------|------|
| `$ARGUMENTS` | Все параметры |
| `$1`, `$2`, ... | N-й параметр |
| `!`command`` | Вывод Shell-команды |
| `@file` | Ссылка на файл |

### Способ через JSON-конфиг

> Источник: [commands.mdx](https://github.com/anomalyco/opencode/blob/dev/packages/web/src/content/docs/commands.mdx)

```json title="opencode.json"
{
  "command": {
    "test": {
      "template": "Запустить тесты и сообщить о failing-тестах",
      "description": "Запуск тестов",
      "agent": "build",
      "model": "anthropic/claude-sonnet-4-20250514",
      "subtask": false
    }
  }
}
```

### Опции конфигурации

| Опция | Тип | Обязат. | Описание |
|------|------|------|------|
| `template` | string | ✅ | Промпт, отправляемый LLM |
| `description` | string | Необязательно | Описание команды в TUI |
| `agent` | string | Необязательно | Agent выполнения команды |
| `model` | string | Необязательно | Переопределение модели по умолчанию |
| `subtask` | boolean | Необязательно | Принудительно выполнить как подзадачу (не засорять главный контекст) |

> **Пояснение subtask**: если указанный agent — subagent, по умолчанию вызывается подзадача. Задайте `subtask: false` для отключения; `subtask: true` принудительно выполняет подзадачей, даже если mode агента primary.
