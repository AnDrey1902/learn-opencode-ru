# Частые вопросы (FAQ)

## 📝 Конспект урока
Ключевые идеи урока в сжатом виде:

     data-zoom-src="/images/appendix/faq-notes.jpeg" />

<summary>📝 Текстовая версия шпаргалки</summary>

1. Установка: `command not found` → PATH; Windows → Scoop/Choco/npm; macOS → `xattr -d`; обновление → чистка `~/.cache/opencode`.
2. Сеть: таймауты → прокси (`export HTTP_PROXY=...`); сертификаты компании → `NODE_EXTRA_CA_CERTS=...`.
3. Модели: ошибки ключа → формат `sk-ant-xxx`; недоступны → баланс/лимиты; 3 способа переключения; multi-provider JSON.
4. Права: `permission.allow` от частых подтверждений; Ctrl+C / `/undo`; режим Plan vs Build; read/edit/bash allow/ask.
5. Скорость: медленно → прокси/маленькая модель/compact; длинный контекст → `/compact`; память → `watcher.ignore`, игнор `node_modules`.
6. Приёмы: память AI → `AGENTS.md` или `CLAUDE.md`; команды export/session/history; файл не меняется → режим Plan.
7. Совместимость: кракозябры → WezTerm/Alacritty + `LANG=en_US.UTF-8`; хоткеи → проверить перехват; VS Code → `code --install-extension`.

## Проблемы установки

### Q: Команда установки ругается "command not found"

**A**: Возможно, неверно настроена переменная окружения PATH.

```bash
# Проверьте место установки
which opencode

# Если вывода нет — добавьте в PATH вручную
# macOS/Linux
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc

# Или глобальная установка через npm
npm install -g @anthropic-ai/opencode
```

---

### Q: Установка падает на Windows

**A**: Рекомендуем ставить пакетным менеджером:

```powershell
# Через Scoop
scoop install opencode

# Через Chocolatey
choco install opencode

# Через npm
npm install -g @anthropic-ai/opencode
```

Запускайте терминал с правами администратора.

---

### Q: macOS ругается «не удаётся проверить разработчика»

**A**: Это ограничение безопасности macOS.

```bash
# Способ 1: кликните приложение правой кнопкой и выберите «Открыть»
# Способ 2: в терминале выполните
xattr -d com.apple.quarantine /path/to/opencode
```

---

### Q: После обновления версии странности в работе

**A**: Попробуйте очистить кэш и переустановить:

```bash
# Очистка кэша
rm -rf ~/.cache/opencode

# Переустановка
opencode upgrade --force
```

## Проблемы сети

### Q: Тайм-ауты подключения "ETIMEDOUT" и "ECONNREFUSED"

**A**: Проблема сетевого подключения, частая у пользователей из России и Китая.

**Способ 1: настройте прокси**
```bash
export HTTP_PROXY=http://127.0.0.1:7890
export HTTPS_PROXY=http://127.0.0.1:7890
opencode
```

**Способ 2: используйте доступные напрямую модели**
```bash
# Прямое подключение без прокси
opencode
/connect  # Выберите доступного провайдера
```

Подробности — [Настройка сети](../1-start/03-network).

---

### Q: Прокси задан, но всё равно не коннектится

**A**: Проверьте по пунктам:

1. Убедитесь, что прокси-приложение запущено
2. Убедитесь в верности порта прокси
3. Проверьте, не нужен ли NO_PROXY
4. Проверьте через `curl`:
```bash
curl -x http://127.0.0.1:7890 https://api.anthropic.com
```

---

### Q: В корпоративной сети нужен сертификат — что делать

**A**: Задайте свой сертификат:

```bash
export NODE_EXTRA_CA_CERTS=/path/to/certificate.pem
opencode
```

Или в файле конфигурации:

```json
{
  "network": {
    "ca_cert": "/path/to/certificate.pem"
  }
}
```

## Проблемы конфигурации моделей
<AdInArticle />

### Q: API-ключ задан, но ругается «ошибка аутентификации»

**A**: Проверьте по пунктам:

1. **Верный формат API-ключа**: у провайдеров форматы разные
   - Anthropic: `sk-ant-xxx`
   - OpenAI: `sk-xxx`
   - DeepSeek: `sk-xxx`

2. **Ключ действителен**: проверьте на сайте провайдера

3. **Верно задана переменная окружения**:
   ```bash
   echo $ANTHROPIC_API_KEY  # Проверьте, есть ли значение
   ```

4. **Верный синтаксис конфига**:
   ```bash
   cat ~/.config/opencode/opencode.json | jq .  # Проверьте формат JSON
   ```

---

### Q: Ругается «модель недоступна» или "quota exceeded"

**A**:

1. **Квота исчерпана**: проверьте баланс счёта провайдера
2. **Неверное имя модели**: проверьте идентификатор модели
3. **Ограничения аккаунта**: отдельные модели — только для платных аккаунтов

```bash
# Список доступных моделей
opencode models
```

---

### Q: Как переключать разные модели

**A**:

**Способ 1: переключение в TUI**
```
/models
```

**Способ 2: указать в командной строке**
```bash
opencode -m deepseek-chat
```

**Способ 3: умолчание в конфиге**
```json
{
  "model": "deepseek-chat"
}
```

---

### Q: Как настроить нескольких провайдеров

**A**: Добавьте нескольких провайдеров в конфиг:

```json
{
  "provider": {
    "anthropic": {
      "options": {
        "apiKey": "{env:ANTHROPIC_API_KEY}"
      }
    },
    "deepseek": {
      "options": {
        "apiKey": "{env:DEEPSEEK_API_KEY}"
      }
    },
    "openai": {
      "options": {
        "apiKey": "{env:OPENAI_API_KEY}"
      }
    }
  }
}
```

Затем переключайтесь через `/models`.

## Проблемы прав

### Q: Каждое действие требует подтверждения — утомительно

**A**: Настройте режим прав:

**Способ 1: автовыдача на сессию**
- Клавишей `a` выберите «разрешать всегда»

**Способ 2: настройка в конфиге**
```json
{
  "permission": {
    "read": "allow",
    "edit": "allow",
    "bash": "allow"
  }
}
```

**Способ 3: точечный контроль**
```json
{
  "permission": {
    "read": "allow",
    "edit": "ask",
    "bash": "ask"
  }
}
```

---

### Q: AI выполнил нежелательную команду

**A**:

1. Сразу прервите через `Ctrl+C`
2. Откатите правки файлов через `/undo`
3. Задайте более строгие права:

```json
{
  "permission": {
    "bash": "ask"
  }
}
```

---

### Q: Как ограничить AI чтением без записи

**A**: Используйте режим Plan:

1. Клавишей `Tab` переключитесь в режим Plan
2. Или задайте Agent при старте:
   ```bash
   opencode -a plan
   ```

## Проблемы производительности

### Q: Медленные ответы

**A**: Возможные причины и решения:

1. **Сетевые задержки**: используйте прокси или доступные напрямую модели
2. **Слишком большая модель**: возьмите модель поменьше (вроде `small_model`)
3. **Слишком длинный контекст**: сожмите контекст через `/compact`

---

### Q: Ошибка из-за слишком длинного контекста

**A**:

```bash
# Ручное сжатие
/compact

# Опции сжатия в конфиге
{
  "compaction": {
    "auto": true,
    "prune": true
  }
}
```

> `auto`: автосжатие при заполнении контекста; `prune`: удаление старых выводов инструментов ради экономии токенов

---

### Q: Высокое потребление памяти

**A**:

1. Закройте неиспользуемые сессии
2. Настройте игнор каталогов монитором файлов:
   ```json
   {
     "watcher": {
       "ignore": ["node_modules/**", "dist/**", ".git/**"]
     }
   }
    ```
3. Используйте модели поменьше

## Функциональные вопросы

### Q: Как заставить AI запомнить мои предпочтения

**A**: Используйте файлы AGENTS.md или CLAUDE.md:

```markdown
<!-- AGENTS.md -->
# Правила проекта

- Используйте TypeScript
- Пакетный менеджер — pnpm, а не npm
- Комментарии кода — на русском
- Соблюдайте правила ESLint
```

Или создайте автоматически через `/init`.

---

### Q: Исторические сессии пропали

**A**:

```bash
# Список всех сессий
opencode session list

# Просмотр в TUI
/sessions
```

Сессии хранятся в `~/.local/share/opencode/sessions/`.

---

### Q: Как узнать session ID текущей сессии

**A**: Два способа:

| Способ | Действие |
|------|------|
| **CLI** | В терминале выполните `opencode session list` — session ID в первом столбце |
| **TUI** | Нажмите `<leader>l` (то есть Ctrl+X → L) для списка сессий — текущая подсвечена |

```bash
# Способ CLI: список всех сессий
opencode session list

# Пример вывода
# Session ID                      Title                    Updated
# ses_2eeb39d82ffecC4m0PQttrXkTa  Заголовок моей сессии  12:54 AM
```

ID текущей сессии подсвечен в списке сессий TUI — выбранная строка и есть он.

---

### Q: Как экспортировать записи диалога

**A**:

```bash
# Экспорт в TUI
/export

# Экспорт из командной строки
opencode session export <session-id> -o conversation.md
```

### Q: Правки файлов не применились

**A**: Проверьте по пунктам:

1. Убедитесь, что в режиме Build (а не Plan)
2. Проверьте права на файлы
3. Посмотрите, нет ли проигнорированных запросов прав
4. Детали операций — через `/details`

---

### Q: Отмена и повтор Git не работают

**A**:

1. Убедитесь, что проект — Git-репозиторий
2. Убедитесь в наличии незакоммиченных изменений
3. Проверьте статус Git:
   ```bash
   git status
   ```

## Проблемы совместимости

### Q: Кракозябры в терминале

**A**:

1. Используйте рекомендованные терминалы: WezTerm, Alacritty, iTerm2
2. Задайте верную кодировку:
   ```bash
   export LANG=en_US.UTF-8
   ```
3. Используйте поддерживаемые шрифты (рекомендуются Nerd Fonts)

---

### Q: Горячие клавиши не работают

**A**:

1. Проверьте, не перехватывает ли их терминал
2. Отдельным терминалам нужна особая настройка
3. Попробуйте слэш-команды вместо клавиш

---

### Q: Расширение VS Code не находится

**A**:

```bash
# Ручная установка расширения
code --install-extension anthropic.opencode

# Или найдите "OpenCode" в VS Code
```
