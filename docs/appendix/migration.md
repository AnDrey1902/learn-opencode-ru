# Гид миграции

> 💡 **Если ваша версия OpenCode 1.0 и выше — этот материал можно пропустить.**

Плавное обновление с OpenCode 0.x до 1.0

---

## Обзор версий

OpenCode 1.0 — полностью переписанный TUI.

Переход с TUI на Go + Bubbletea на внутренний фреймворк OpenTUI (Zig + SolidJS) решил проблемы производительности и функциональности.

Новый TUI работает так же, как старый, потому что подключается к тому же серверу OpenCode.

---

## Способы обновления

### Автообновление

```bash
# Обновить до 1.0
opencode upgrade 1.0.0

# Откатить на 0.x
opencode upgrade 0.15.31
```

### Ручное обновление

```bash
# npm
npm install -g opencode-ai

# Homebrew
brew upgrade opencode

# Scoop
scoop update opencode
```

> Обратите внимание: старые версии могут не обновляться до 1.0 автоматически. Некоторые совсем старые версии сами подтягивают свежие.

---

## Изменения UX
<AdInArticle />

1. **Компактнее история сессий** — полные детали только инструментов edit и bash

2. **Новая палитра команд** — по `Ctrl+P` в любом контексте: все доступные действия

3. **Новая боковая панель сессий** — переключаемая, с полезной информацией

4. **Убраны отдельные функции** — убрали то, чем, возможно, никто не пользовался. Не хватает важного — создайте Issue

## Breaking Changes

### Переименованные привязки

| Старое имя | Новое имя |
|--------|--------|
| `messages_revert` | `messages_undo` |
| `switch_agent` | `agent_cycle` |
| `switch_agent_reverse` | `agent_cycle_reverse` |
| `switch_mode` | `agent_cycle` |
| `switch_mode_reverse` | `agent_cycle_reverse` |

### Удалённые привязки

Следующие привязки удалены:

- `messages_layout_toggle`
- `messages_next`
- `messages_previous`
- `file_diff_toggle`
- `file_search`
- `file_close`
- `file_list`
- `app_help`
- `project_init`
- `tool_details`
- `thinking_blocks`

Если они использовались в вашей конфигурации — удалите их.

## Чек-лист миграции

### До обновления

- [ ] Сохраните текущие файлы конфигурации
- [ ] Запишите используемые модели и настройки
- [ ] Экспортируйте важные записи сессий

### Во время обновления

- [ ] Выполните `opencode upgrade 1.0.0`
- [ ] Проверьте конфигурацию привязок, удалите устаревшие
- [ ] Обновите переименованные привязки

### После обновления

- [ ] Убедитесь, что `opencode --version` показывает 1.x
- [ ] Проверьте подключение моделей через `/models`
- [ ] Проверьте базовые функции диалога
- [ ] Проверьте своих Agent и Skill
- [ ] Освойте новую палитру команд (Ctrl+P)
