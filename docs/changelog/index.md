## Как обновиться

```bash
# Автообновление до последней версии
opencode upgrade

# Текущая версия
opencode --version
```

Автообновление в OpenCode включено по умолчанию, обычно руками ничего делать не надо. Чтобы выключить, задайте в конфигурации:

```json
{
  "autoupdate": false
}
```

## Про версии

- **Мажорная** (например, 1.x.x → 2.x.x): крупные обновления, возможны несовместимые изменения
- **Минорная** (например, 1.1.x → 1.2.x): выход новых функций
- **Патч** (например, 1.1.10 → 1.1.11): фиксы багов и мелкие улучшения

_Новые версии добавляются сюда по мере выхода_
