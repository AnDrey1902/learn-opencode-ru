# OpenCode v1.18.20 — журнал обновлений

**Дата выхода**: 2026-08-21

## Коротко

Упавшие задачи суб-агентов возвращают возобновляемый `task_id`, расширены сценарии повторов сетевых ошибок Provider.

## Новое и изменения

- Упавший вызов инструмента суб-агента показывает возобновляемый `task_id` вместо пустого результата.
- `opencode run` умеет отвечать на запросы разрешений от суб-агентов.

## Исправления

- Повтор при `finish_reason: network_error` от Provider, покрыты формы `network-error`, `network_error` и другие сетевые ошибки.
- Ошибки стрима xAI (нет мощностей, временно недоступно) повторяются.
- `max_completion_tokens` Cerebras сохраняется как есть, без добавочного лимита сверху.
- Вместе с MCP SSE-фиксом из v1.18.11 расширено покрытие повторов сетевых сбоев.

## Кого касается

Суб-агенты, `opencode run`, сетевые повторы Provider, пользователи xAI и Cerebras.

## Стоит ли обновляться

Тем, кто пользуется суб-агентами или часто ловит временные сетевые сбои, — рекомендуется; остальным — по желанию.

## Команда обновления

```bash
opencode upgrade
```
