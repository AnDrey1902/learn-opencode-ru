# OpenCode v1.18.17 — журнал обновлений

**Дата выхода**: 2026-08-12

## Коротко

Сжатие сессий сохраняет полные свежие раунды, автоповторы ограничены против штормов повторов.

## Новое и изменения

- Сжатие сессий сохраняет полные свежие раунды и даёт малым моделям более чёткие саммари.
- MERGE Gateway добавляет рассуждающие варианты; модели GitHub Copilot с PDF-зрением принимают PDF-вложения.
- DeepSeek V4 Flash использует корректные дефолты сэмплирования, серия Muse — корректные Meta-системные промпты.

## Исправления

- У автоповторов сессий появились лимит и случайный джиттер — меньше штормов повторов.
- Модель по умолчанию берётся из текущего значения сервера, а не из протухшего локального конфига.
- Китайские dev-термины заменены на более общие формулировки.

## Кого касается

Пользователи длинных сессий и малых моделей, а также MERGE Gateway, GitHub Copilot, DeepSeek, Meta Muse и мультисерверов.

## Стоит ли обновляться

Тем, у кого длинные сессии, частые повторы или эти модели, — рекомендуется; остальным — по желанию.

## Команда обновления

```bash
opencode upgrade
```
