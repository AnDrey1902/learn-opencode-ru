# OpenCode v1.18.15 — журнал обновлений

**Дата выхода**: 2026-08-07

## Коротко

Порядок сообщений теперь строго по реальному времени — старые ID больше не влияют на таймлайн, откат, форки и список сессий.

## Новое и изменения

- Полную запись сессии можно экспортировать в JSON прямо из интерфейса.
- В Desktop шире языковое покрытие, селектор языков хранит родные названия, переводы дополнены.
- В конфиге хоткеев TUI уже есть бинды diff, фоновых сессий, Skill и cursor; бинд гасится через `none` или `false`.

## Исправления

- При импорте или неупорядоченных ID старых сообщений порядок всё равно по времени создания; откат и форки тоже идут по реальному времени.
- Надёжнее границы таймлайна сессий, порядок persist-сообщений и сортировка списка по времени активности.
- Повторное сжатие сохраняет более раннюю историю вызовов инструментов, чистка усечения надёжнее по времени файлов.
- Починена загрузка Blob-вложений в Web UI.

## Кого касается

Импортированные/мигрированные старые сессии, откат/форки, сжатие сессий, веб-вложения, хоткеи TUI и многоязычные пользователи Desktop.

## Стоит ли обновляться

Тем, кто пользуется старыми сессиями, откатом/форками или экспортом сессий, — рекомендуется; остальным — по желанию.

## Команда обновления

```bash
opencode upgrade
```
