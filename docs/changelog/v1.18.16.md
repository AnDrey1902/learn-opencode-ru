# OpenCode v1.18.16 — журнал обновлений

**Дата выхода**: 2026-08-10

## Коротко

Парсинг конфигурации терпит неизвестные верхнеуровневые поля, улучшены поиск проектов, контекстное меню и поведение окон macOS в Desktop.

## Новое и изменения

- Парсинг конфигурации игнорирует неизвестные верхнеуровневые поля и больше не падает на них.
- v2 находит только `opencode.json` и `opencode.jsonc`; v1-loader по-прежнему читает старый глобальный `config.json`, новые глобальные конфиги по умолчанию — `opencode.jsonc`.
- Открытый с главной проект регистрируется в остальных областях приложения, меню проекта открывается по правому клику.
- Если сервер селектора проектов не умеет в поиск — откат на локальный листинг каталогов и матчинг.
- На macOS приложение живёт после закрытия последнего окна и переоткрывает окно при повторной активации.

## Исправления

- В упрощённом китайском token-метки используют «词元», термины в проекте обновлены соответственно.

## Кого касается

Файлы конфигурации, управление проектами Desktop, китайский интерфейс и пользователи macOS. Тем, у кого старый глобальный `config.json`, обратите внимание на разницу обнаружения v1/v2.

## Стоит ли обновляться

Тем, кто ловил ошибки на неизвестных полях конфига или пользуется этими сценариями Desktop, — рекомендуется; перед миграцией конфига проверьте, v1 у вас или v2.

## Команда обновления

```bash
opencode upgrade
```
