# OpenCode v1.18.19 — журнал обновлений

**Дата выхода**: 2026-08-20

## Коротко

Версия добавляет нативный passthrough OpenAI и Anthropic для Cloudflare AI Gateway и улучшает соединения ряда Provider и аккаунтов.

## Новое и изменения

- Модели Cloudflare AI Gateway поддерживают нативный passthrough OpenAI и Anthropic.
- OpenCode Go Provider включает веб-поиск, обновлён дефолтный Console URL в процессе привязки аккаунта.
- Настройка compute residency рабочей области ChatGPT прокидывается в запросы Codex.

## Исправления

- Лимиты Codex приближены к лимитам подписки ChatGPT, убраны possibly-неподдерживаемые встроенные дефолты сэмплирования Qwen.
- `/connect` корректно показывает аутентифицированные Provider, аномальные цены моделей больше не ломают расчёт стоимости.
- Запросы OpenAI WebSocket сверх лимита размера сообщения откатываются назад.
- Сохранена совместимость БД v1, в диалоге серверов можно править сохранённые серверы.

## Кого касается

Пользователи Cloudflare AI Gateway, OpenAI, Anthropic, Codex, Qwen, OpenCode Go и БД v1.

## Стоит ли обновляться

Тем, кто пользуется этими Provider или процедурами привязки, — рекомендуется; остальным — по желанию.

## Команда обновления

```bash
opencode upgrade
```
