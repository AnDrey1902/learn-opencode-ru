# OpenCode v1.18.14 — журнал обновлений

**Дата выхода**: 2026-08-05

## Коротко

Вход в xAI унифицирован на процесс по коду устройства — удобнее для headless и удалённых окружений; стабильнее Provider и удалённые workspaces.

## Новое и изменения

- Вход в xAI сведён к единому процессу по коду устройства — лучше для headless и удалёнки.
- Статистика расхода ACP теперь включает записи в кэш.

## Исправления

- Структурированные ошибки Provider в стриме сохраняются, повторов временных ошибок Provider и сети стало больше.
- Удалённые workspaces больше не получают хостовый путь `directory`, промпты резолвятся от корня удалённого проекта.
- Тела 5xx-ответов удалённых workspaces пишутся в хостовый лог — проще разбирать сбои прокси.
- ACP дожидается завершения queued-обновлений сессии перед концом раунда.

## Кого касается

Пользователи xAI, ACP, удалённых workspaces, прокси-окружений и интеграций Provider.

## Стоит ли обновляться

Тем, кто входит в xAI в headless, пользуется удалёнными workspaces или ловит временные сетевые сбои, — рекомендуется.

## Команда обновления

```bash
opencode upgrade
```
