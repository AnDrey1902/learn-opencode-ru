# OpenCode v1.18.22 — журнал обновлений

**Дата выхода**: 2026-08-24

## Коротко

В версии убраны устаревшие сведения о скидке OpenCode Go, починены вход с устройства, OpenAI-совместимые Provider и адаптация Bedrock.

## Новое и изменения

- Убраны просроченные тексты про скидку первого месяца OpenCode Go и цены.
- При скролле селектора моделей заголовки групп Provider остаются видимыми.

## Исправления

- Починена ссылка входа с устройства OpenCode, когда сервер возвращает относительный URL проверки или base path.
- Параметр `textVerbosity` больше не отправляется OpenAI-совместимым Provider, которые его не поддерживают.
- Обновлён Amazon Bedrock Provider для совместимости.

## Кого касается

Пользователи OpenCode Go, входа по коду устройства, OpenAI-совместимых Provider, Amazon Bedrock и селектора моделей.

## Стоит ли обновляться

Тем, кто пользуется входом с устройства, OpenAI-совместимыми Provider или Bedrock, — рекомендуется; остальным — по желанию.

## Команда обновления

```bash
opencode upgrade
```
