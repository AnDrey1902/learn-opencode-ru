# OpenCode v1.18.21 — журнал обновлений

**Дата выхода**: 2026-08-21

## Коротко

Версия не даёт модели останавливаться раньше времени при неизвестной причине завершения и чинит мультирегиональную маршрутизацию Gemini в Vertex AI.

## Новое и изменения

- При неизвестной причине завершения модель продолжает отвечать, а не останавливается раньше.
- Команда архивации сессий зарегистрирована в обоих layout Desktop.

## Исправления

- Мультирегиональные запросы Gemini (`eu`/`us`) в Vertex AI идут через REP-эндпоинт.
- При следующей загрузке поиска по файлам старые результаты сохраняются — интерфейс меньше мигает пустотой.

## Кого касается

Продолжение ответов модели, Gemini в Vertex AI, архивация сессий и поиск по файлам в Desktop.

## Стоит ли обновляться

Пользователям Vertex AI и тем, у кого ответы обрывались раньше времени, — рекомендуется; остальным — по желанию.

## Команда обновления

```bash
opencode upgrade
```
