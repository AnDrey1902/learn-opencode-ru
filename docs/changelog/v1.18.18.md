# OpenCode v1.18.18 — журнал обновлений

**Дата выхода**: 2026-08-13

## Коротко

Версия чинит системные промпты моделей Kimi и адаптацию максимальной силы рассуждений xAI.

## Новое и изменения

В Release Notes этой версии новые функции и изменения отдельно не выделены.

## Исправления

- Для официальных Provider Moonshot и Kimi корректно выбирается системный промпт Kimi.
- Починена сила рассуждений `xhigh` у моделей xAI.

## Кого касается

В основном пользователи моделей Moonshot, Kimi и xAI.

## Стоит ли обновляться

Тем, кто пользуется этими моделями, — рекомендуется; остальным — по желанию.

## Команда обновления

```bash
opencode upgrade
```
