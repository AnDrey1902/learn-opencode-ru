# OpenCode v1.18.13 — журнал обновлений

**Дата выхода**: 2026-08-04

## Коротко

К ревью GitHub PR добавлен ссылочный контекст, в Desktop расширены многоязычность и поддержка письма справа налево.

## Новое и изменения

- Контекст ревью GitHub Pull Request теперь включает номер и URL PR.
- В Desktop и видах сессий — начальная поддержка RTL, плюральные правила по языкам и новые языки.
- Расширено покрытие локализации десктопных текстов: нативные меню, диалоги обновлений, помощь и т.д.
- Парсинг Markdown вынесен из главного потока — интерфейс отзывчив при рендере сообщений.

## Исправления

- Починены RTL-проблемы вкладок, drawer, зума, заголовков окон, иконок направлений и др.
- Сессии без названий получают сгенерированное имя вместо пустоты.

## Кого касается

Ревью GitHub PR, i18n-пользователи Desktop/Web и сессии с объёмным контентом.

## Стоит ли обновляться

Тем, кто пользуется GitHub-ревью, RTL-языками или многоязычным Desktop, — рекомендуется; остальным — по желанию.

## Команда обновления

```bash
opencode upgrade
```
