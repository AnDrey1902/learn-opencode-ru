# Этап 3: эффективный рабочий процесс

> 💡 **Цель**: освоить режимы Plan и Build, совместную работу с Agent, инициализацию проекта

## 🎯 Цели этапа

- Понимать разницу между режимами Plan и Build
- Уметь вызывать разных Agent для выполнения задач
- Использовать `/init`, чтобы AI разобрался в вашем проекте

## ⏳ Сколько времени займёт

45 минут — 1 час

## 🚀 Перед началом

- Пройдены первый и второй этапы
- Есть реальный проект (подойдёт код или тексты)

## 🎒 Что вы получите

После прохождения этапа вы сможете:

1. Понимать, когда использовать режим Plan, а когда — Build
2. Вызывать разных Agent для профессиональных задач
3. Генерировать файл правил проекта через `/init`
