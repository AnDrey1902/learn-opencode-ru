## Основная идея

### Что такое Agent

Agent — участники вашей AI-команды, у каждого своя специализация:

- **Build Agent**: универсальный разработчик — читает и пишет файлы, выполняет команды
- **Plan Agent**: аналитик-планировщик — в основном анализирует код и даёт рекомендации (может писать `.opencode/plans/*.md`, чтобы сохранить план)
- **Explore Agent**: исследователь кода — быстро разбирается в структуре кодовой базы
- **General Agent**: универсальный помощник — силён в сложных исследованиях и многошаговых задачах

### Два типа

| Тип | Описание | Как вызвать |
|-----|------|---------|
| **Primary Agent (главный агент)** | Agent, с которым вы общаетесь напрямую (Build, Plan) | Переключение через <kbd>Tab</kbd> |
| **Subagent (под-агент)** | Эксперт, которого вызывает главный агент автоматически или вы вручную (Explore, General) | `@имя_агента задача` |

### Встроенные Agent: краткий обзор

<AdInArticle />

| Agent | Тип | Специализация | Разрешения по умолчанию |
|-------|------|------|---------|
| Build | Primary | Универсальная разработка (главный Agent по умолчанию) | Все (чтение и запись файлов, команды) |
| Plan | Primary | Анализ кода, планирование, ревью | Ограниченные (правка запрещена, запись разрешена только в `.opencode/plans/*.md`) |
| Explore | Subagent | Быстрый поиск файлов, поиск по коду, ответы о кодовой базе | Только чтение (поиск, просмотр кода) |
| General | Subagent | Сложные исследования, многошаговые задачи, случаи, когда неясно, найдётся ли ответ быстро | Многозадачность (доступен инструмент Todo) |

::: details 🔧 Внутренние Agent (работают автоматически, вызывать не нужно)
В OpenCode есть ещё 3 скрытых внутренних Agent, работающих в фоне:

| Agent | Роль | Когда срабатывает |
|-------|------|---------|
| **compaction** | Сжатие контекста | Когда диалог приближается к лимиту контекста модели — автоматически сжимает историю |
| **title** | Генерация заголовка сессии | После создания новой сессии автоматически придумывает описательный заголовок |
| **summary** | Генерация сводки сессии | При сжатии сессии заменяет историю сводкой |

Вызывать их напрямую не нужно — OpenCode задействует их сам, когда потребуется.
:::

## Повторите за мной

### Шаг 1: посмотрите текущего Agent

**Зачем**
Понять, какой Agent сейчас работает.

Взгляните на строку состояния — там имя текущего Agent (например, `Build` или `Plan`).

### Шаг 2: переключите главного Agent через Tab

**Зачем**
Переключиться между Build Agent и Plan Agent.

Нажмите <kbd>Tab</kbd>.

### Шаг 3: вызовите Explore Agent

**Зачем**
Поручить разбор проекта профильному Agent-исследователю.

Введите:

```
@explore разбери общую структуру этого проекта
```

**Вы должны увидеть**: Explore Agent начнёт работу и проанализирует структуру проекта

::: tip 💡 Три глубины исследования Explore
При вызове Explore AI сам выберет глубину по описанию задачи. Её можно задать и явно в промпте:

| Глубина | Описание | Подходит для |
|------|------|---------|
| **quick** | Базовый поиск, быстрое позиционирование | «Найди, где лежит config-файл» |
| **medium** | Среднее исследование, баланс скорости и охвата | «Разбери структуру проекта» |
| **very thorough** | Полный анализ, поиск по разным местам и соглашениям об именах | «Найди весь код, связанный с безопасностью» |

Например, для максимально тщательного исследования пишите так:

```
@explore тщательно разбери реализацию аутентификации и авторизации в этом проекте, максимально подробно
```

AI увидит слова «тщательно» и «максимально подробно» и сам выберет уровень very thorough.
:::

::: tip 💡 Сессии под-агентов
После вызова под-агента создаётся дочерняя сессия. Клавишей `<leader>→` можно войти в неё, `<leader>←` — вернуться в родительскую. (По умолчанию leader — `Ctrl`+`X`)
:::

### Шаг 4: вызовите General Agent

**Зачем**
General Agent силён в сложных исследованиях и многошаговых задачах.

Введите:

```
@general исследуй сравнение производительности Node.js и Python и выдай сводный отчёт
```

**Вы должны увидеть**: General Agent параллельно выполнит несколько исследовательских задач и сведёт результаты

### Шаг 5: пусть главный Agent сам вызовет под-агента

**Зачем**
Главный Agent сам решает по описанию задачи и полю description Agent'а, нужен ли под-агент.

Введите сложную задачу:

```
Разбери структуру кода этого проекта, а затем добавь README.md
```

**Вы должны увидеть**: Build Agent, возможно, сам вызовет Explore Agent для разбора структуры, а README создаст сам

::: tip 💡 Правила автовызова
Главный Agent решает о вызове по полю `description` под-агента. Например, у Explore там «быстро находить файлы, искать по коду» — и когда задача связана с поиском по кодовой базе, он вызывается.
:::

### Шаг 5.5: посмотрите список Agent

**Зачем**
Узнать, какие Agent сейчас доступны.

Нажмите `<leader>a` для списка всех Agent (по умолчанию leader — `Ctrl`+`X`, то есть `Ctrl`+`X`+`a`)

**Вы должны увидеть**:
- Primary Agents: build, plan
- Subagents: explore, general
- А также ваши собственные Agent (если есть)

Выйти из списка — <kbd>Esc</kbd>.

### Шаг 6: перемещайтесь между родительской и дочерними сессиями

**Зачем**
Посмотреть подробный ход работы под-агента или переключаться между главной и дочерними сессиями.

- `<leader>→` — следующая сессия (родитель → ребёнок1 → ребёнок2 → … → родитель)
- `<leader>←` — предыдущая сессия (родитель ← ребёнок1 ← ребёнок2 ← … ← родитель)
- `<leader>↑` — сразу к родительской сессии

**Пример иерархии сессий**:
```
Главная сессия (Build)
  └── Дочерняя сессия (Explore)
        └── Внучатая сессия (General)
```

Навигационными клавишами свободно перемещайтесь между уровнями.

::: tip 💡 Горячие клавиши по умолчанию
- Клавиша `leader` по умолчанию — `Ctrl`+`X`
- `<leader>→` = `Ctrl`+`X`+`→` (стрелка вправо)
- `<leader>←` = `Ctrl`+`X`+`←` (стрелка влево)
- `<leader>↑` = `Ctrl`+`X`+`↑` (стрелка вверх)
:::

## Типичные проблемы

| Симптом | Причина | Решение |
|-----|-----|-----|
| `@имя_агента` не реагирует | Опечатка в имени или это не под-агент | Проверьте написание; встроенные под-агенты — `explore` и `general`. Главных (`build`, `plan`) переключают только через <kbd>Tab</kbd> |
| Дочерней сессии не видно | Не раскрыли или ушли не на тот уровень | Перемещайтесь через `<leader>→` / `<leader>←` или вернитесь клавишей `<leader>↑` |
| Хотите в Explore, но Tab не находит | <kbd>Tab</kbd> переключает только главных (Primary Agent) | Explore — под-агент (Subagent), вызывается только через `@explore` |
| Под-агент прервался и пропал | Сессия могла закрыться или вы не на том уровне | Вернитесь клавишей `<leader>↑`, затем найдите через `<leader>→` |
| Plan Agent спрашивает «разрешить правку?» | У Plan Agent по умолчанию `edit: deny` (правка запрещена, разрешены только `.opencode/plans/*.md` и глобальный каталог plans) | Это нормально: Plan — для анализа; для правок переключитесь на Build Agent |
| General Agent не выполняет многошаговую задачу | Описание задачи нечёткое или задача недостаточно сложная | Чётко перечислите нужные шаги или убедитесь, что задача правда многошаговая |
